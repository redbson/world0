## 摘要

World 0 是一个面向 LLM Agent 的概念世界认知层：概念与带类型的关系构成一张图，
观察流在其上引起强化、共现学习与遗忘，任务条件下的扩散激活与多样性选择从中
投影出一个小的局部视图。本文给出该系统当前实现的完整形式模型，并对其动力学与
算法性质给出证明。主要结果包括：

1. **时间**：以观察次数为单位的认知时钟下，遗忘算子满足带显式误差项的半群性质
   （命题 3.1）；配合"使用前结算"，遗忘量与反思（reflect）的调用频率无关（定理 3.2）。
2. **证据与噪声**：被确认不超过 6 次的概念，其证据地板低于褪色阈值，必然被遗忘；
   第 7 次确认起地板越过阈值（命题 3.3）。可靠性分级、显著性持续时间、关系存续
   时间均有闭式（命题 3.5、4.3、10.1）。
3. **共现学习**：Jaccard 关联恰是两个条件概率的调和型组合
   $J = (1/P(b\mid a) + 1/P(a\mid b) - 1)^{-1}$（引理 5.1），因此阈值 0.2 在对称情形下
   等价于 $P(b\mid a) \ge 1/3$；独立噪声的渐近关联为 $q/(2-q)$（命题 5.2）。
4. **激活**：有界 noisy-OR 是以最强种子分数 $S$ 为上界的 t-余模；任何被传播到的概念
   都不超过 $S$（定理 6.3）；秩保持地板使深度 $D$ 内经非负边可达的概念全部进入候选
   （定理 6.4）；一次激活的代价与被触及的子图大小成线性（命题 6.5）。
5. **投影与焦点**：种子总在投影中（命题 7.1）；与任务无关的候选在 MMR 中等价于完全
   冗余的重复项（命题 7.3）；持续焦点容量有界、单次点燃恰好保留 3 次投影、只偏置
   不注入（命题 8.1–8.3）。
6. **预测误差**：以模型自身的伯努利预测为零假设，缺席误差的分子无偏，期望误差有
   上界 $\tfrac12\sqrt{\sum p^3(1-p)}/\sum p^2$（定理 9.2）；新组合的权重是独立假设下
   "本应已相遇"概率的保守估计（命题 9.3）。

形式化过程本身发现了实现与设计意图不一致的五处缺陷（§12，F1–F5），其中最重要的
是：激活会移动衰减参照点，而此前在两次使用之间未结算的衰减被直接丢弃，导致遗忘
量取决于 reflect 的调用频率——同一概念在不同调用习惯下置信度可以是 0.31 或 0.93。
五处均已修复，并由回归测试固定。

World 0 的设计文档（`AGENTS.md`）用自然语言规定了系统应具备的性质：概念优先、
关系有类型、上下文改变相关性、投影是运行时输出、系统可逐步演化而不坍缩为语义
蔓延。前十八轮开发以探针（probe）驱动：先测量一个行为，发现缺陷，修复，再测量。
这种方法能发现"已经出错"的地方，但不能说明"为什么不会出错"。

本文的目标是后者：把当前实现中的每个算子写成数学对象，陈述它们应当满足的性质，
给出证明，并在代码上逐一数值检验。三点方法约定：

- **只陈述实现真正满足的性质。** 若证明需要某个前提（例如成熟度轨迹相同、独立
  性假设），前提会显式写出；若实现不满足某个"本应成立"的性质，就把它作为缺陷
  记录并修复（§12），而不是修改命题去迁就实现。
- **常数是给定的。** 半衰期、阈值等常数来自此前各轮的标定（分析文档 §5 及各节），
  本文不论证它们的最优性，只推导它们的推论（例如"6 次"、"3 次投影"、"974 次观察"
  这些由常数决定的临界值）。
- **可复现。** `python docs/paper/verify.py` 输出本文引用的全部数值。

## 2. 形式模型

### 2.1 世界状态

在认知时刻 $t \in \mathbb{N}$，世界状态为

$$
\mathcal{W}_t = (V_t,\ E_t,\ \Theta_t,\ \mathcal{F}_t),
$$

- $V_t$：概念集合。概念 $v$ 的动力学状态是
  $x_v = (c_v, m_v, n_v, d_v, t^{a}_v, t^{d}_v, \rho_v, \pi_v)$：置信度 $c_v\in[0,1]$、
  成熟度 $m_v \in \{\textsf{emb},\textsf{dev},\textsf{est},\textsf{core},\textsf{fad}\}$、
  确认次数 $n_v$、否证次数 $d_v$、最近激活时刻 $t^a_v$、最近结算时刻 $t^d_v$、
  复现窗口数 $\rho_v$、任务画像 $\pi_v$（任务标签 → 次数）。
- $E_t$：关系集合。关系 $e=(u\to w)$ 的状态是
  $y_e = (\text{axis}_e, \sigma_e, w_e, k_e, p_e, r_e, \delta_e, t^r_e, t^d_e, \chi_e)$：
  轴（positive / negative / parallel）、语义关系名 $\sigma_e$、操作权重 $w_e$、结构
  置信度 $k_e$、语义概率 $p_e$（"该类型关系正确"的信念）、强化次数 $r_e$、否证次数
  $\delta_e$、最近强化与结算时刻、是否显式声明 $\chi_e$。
- $\Theta_t$：学习统计（`dynamics/hebbian.py`）：观察数 $N$、提及数 $n(a)$、未联结对的
  待定共现数、已联结对的共现数 $C(a,b)$。
- $\mathcal{F}_t$：持续焦点（`context/focus.py`，可选）：至多 7 个概念及其强度。

概念的**证据**与**显著性**是状态的函数（§3.4），不是独立状态。

### 2.2 认知时钟

**定义 2.1（认知经过时间，`schemas/clock.py:cognitive_elapsed`）。** 两个时刻
$(t_1, h_1)$、$(t_0, h_0)$（观察计数与墙钟小时）之间的认知经过时间为

$$
\Delta\big((t_1,h_1),(t_0,h_0)\big) = \max(0,\ t_1 - t_0) + \beta \max(0,\ h_1 - h_0),
\qquad \beta = 0.1 .
$$

每次 `ingest()` 使 $t$ 加一；墙钟只作为闲置时的缓慢漂移（空闲一天约 2.4 个 tick）。

**命题 2.1（可加性）。** 对单调的三个时刻 $s_0 \le s_1 \le s_2$（两个分量都单调），
$\Delta(s_2, s_0) = \Delta(s_2, s_1) + \Delta(s_1, s_0)$。

*证明.* 单调时两个 $\max$ 都取第一项，两个分量各自是差分，可加。$\square$

可加性是 §3 半群性质的前提：遗忘只能是经过时间的函数，而经过时间必须可以任意
切分。下文把 $\Delta$ 简记为 tick 差。

### 2.3 算子

系统由五个算子驱动（`world/facade.py`）：

| 算子 | 触发 | 作用（按执行顺序） |
|---|---|---|
| $\mathsf{Ingest}(o)$ | 每次观察 | 时钟 +1 → 解析 / 创建概念 → **结算**并激活 → 显式关系（发现 / 强化 + 确认 / 削弱对立主张） → **预测误差** → 共现学习 → 描述 → 否证 → 色场 |
| $\mathsf{Settle}_t(\cdot)$ | 每次强化之前；reflect 时对全体 | 把自上次结算以来欠下的衰减施加到置信度 / 权重上 |
| $\mathsf{Activate}(S)$ | 投影时 | 分层扩散激活，兴奋与抑制两通道 |
| $\mathsf{Project}(a)$ | 投影时 | 种子优先 + 任务感知 MMR，附元认知与注意轨迹 |
| $\mathsf{Reflect}$ | 显式或每 $N$ 次观察 | 全体结算 → [社群、色场] → 生命周期 → 剪枝 |

## 3. 概念动力学

### 3.1 增益

**定义 3.1（激活增益，`ConceptNode.activate`）。** 第 $n$ 次确认（$n$ 为确认后的计数）
使置信度增加

$$
b(n) = \frac{0.06}{1 + 0.08\,n}, \qquad c \leftarrow \min(1,\ c + b(n)).
$$

新概念以 $c_0 = 0.15$ 创建，并立即被确认一次，因此首次提及后 $c = 0.15 + b(1) \approx 0.2056$。

由于 $\sum_k b(k)$ 发散（调和级数），没有衰减时任意高的置信度都可达到：累计增益
$\sum_{k=1}^{N} b(k) \approx 0.75 \ln\frac{1+0.08N}{1.08}$，到达 0.6 需约 12 次（积分估计），
实际离散求和为 **11 次**（`verify.py §3.1`）。

### 3.2 结算：带地板的松弛

**定义 3.2（有效半衰期与证据地板，`decay.concept_half_life`、`decay.evidence_floor`）。**

$$
H(m, n) = \min\!\Big(H_{\max},\ H_m \cdot \min\big(s_{\max},\ 1 + g\,(n-1)^+\big)\Big),
$$

$$
f(n, d, \tau) = \phi_{\max}\cdot \frac{n+1}{n+d+2}\cdot\Big(\frac{n}{n+K}\Big)^{2} \cdot 2^{-\tau/\mathcal{E}},
$$

其中 $\tau$ 是距最近一次激活的认知时间。$\frac{n+1}{n+d+2}$ 是 Beta(1,1) 先验下确认 / 否证
的后验均值。

**定义 3.3（结算算子，`decay.settle_concept`）。** 设上次结算（或激活，取较晚者）在
时刻 $t_0$，当前时刻 $t_1$，$\Delta = t_1 - t_0 \ge 1$，$r = 2^{-\Delta/H(m,n)}$，
$f_1 = f(n, d, t_1 - t^a)$。若 $c > f_1$，则

$$
c \leftarrow f_1 + (c - f_1)\, r ;
$$

否则 $c$ 不变。无论哪种情况，参照点都移到 $t_1$。若结果低于 $\theta_{\text{fade}}$，则
成熟度记为 fading。$\Delta < 1$ 时跳过，参照点不动（未施加的间隔不丢失）。

这是一个向移动目标 $f(t)$ 的 Ornstein–Uhlenbeck 式离散松弛。

**命题 3.1（带时代修正的半群性质）。** 设在 $[t_0, t_k]$ 内没有激活，成熟度不变，
且 $c(t_0) \ge f(t_0)$。把区间任意切分为 $t_0 < t_1 < \dots < t_k$ 并依次结算，得到
$c_{\text{split}}$；一次性结算得到 $c_{\text{whole}}$。则

$$
0 \;\le\; c_{\text{split}} - c_{\text{whole}} \;\le\; f(t_0) - f(t_k) \;\le\; \phi_{\max}\big(1 - 2^{-(t_k - t_0)/\mathcal{E}}\big).
$$

特别地，两段切分的差恰为 $r_2 (1 - r_1)(f_1 - f_2)$；当地板不随时间变化（$n=0$，或忽略
时代项）时，结算是严格的半群：切分方式不影响结果。

*证明.* 记 $f_j = f(t_j)$，$r_j = 2^{-(t_j - t_{j-1})/H}$，$R_j = \prod_{i \le j} r_i$，
$W_j = f_j + (c_0 - f_j) R_j$ 为从 $t_0$ 一次性结算到 $t_j$ 的结果，$D_j = c_j - W_j$。
由于 $f$ 随时间单调不增且 $c_j \ge f_j \ge f_{j+1}$（归纳），每一步都处于"$c > f$"分支：

$$
\begin{aligned}
c_{j+1} - W_{j+1}
&= (c_j - f_{j+1})\,r_{j+1} - (c_0 - f_{j+1})\,R_{j+1} \\
&= r_{j+1}\big[\,f_j + (c_0 - f_j)R_j + D_j - f_{j+1} - (c_0 - f_{j+1})R_j\,\big] \\
&= r_{j+1}\big[\,D_j + (f_j - f_{j+1})(1 - R_j)\,\big].
\end{aligned}
$$

$D_1 = 0$（第一步与一次性结算相同，$R_0 = 1$）。递推式各项非负，故 $D_k \ge 0$；又
$r_{j+1} \le 1$、$1 - R_j \le 1$，得 $D_{j+1} \le D_j + (f_j - f_{j+1})$，累加得
$D_k \le f_1 - f_k \le f_0 - f_k$。$k=2$ 时 $D_2 = r_2 (1 - r_1)(f_1 - f_2)$。
最后一个不等式由 $f \le \phi_{\max} 2^{-\tau/\mathcal{E}}$ 得出。$\square$

数值上，这个修正非常小：$n=40$、切分 2000 + 3000 时差为 0.0082，与闭式逐位一致
（`verify.py §3.2`）。

**定理 3.2（遗忘与 reflect 频率无关）。** 设一个概念在时刻 $a_1 < a_2 < \dots$ 被使用，
每次使用前先结算（`ConceptManager.reinforce`、`ActivationEngine` 的 `record` 路径都
这样做），此外 reflect 可以在任意时刻对它结算。若两种 reflect 安排下成熟度轨迹相同，
则任意时刻两者的置信度之差不超过各使用间隔内地板下降量之和：

$$
\big|c^{(1)}(t) - c^{(2)}(t)\big| \;\le\; \sum_{i} \big(f(a_i^+) - f(a_{i+1}^-)\big).
$$

*证明.* 在每个使用间隔内，两种安排都是命题 3.1 意义下的切分，且区间终点（下一次
使用之前）都做了结算，因此间隔终点处的差 $D$ 满足 $0 \le D \le$ 该间隔的地板下降量。
使用时两者加上相同的增益 $b(n)$（只依赖计数）；截断 $\min(1,\cdot)$ 是 1-Lipschitz 的，
差不扩大。下一间隔的松弛把已有差乘以 $r \le 1$，并可能再引入该间隔的地板下降量
（命题 3.1 的递推）。按间隔归纳即得。$\square$

没有"使用前结算"时这个定理不成立：激活把参照点移到"现在"，两次使用之间若没有
reflect，那段衰减就永远丢失了。这正是 §12 的缺陷 F4。修复前后，每 24 次观察使用
一次、共 30 次后的置信度：

| reflect 频率 | 每 1 次 | 每 50 次 | 每 1000 次 | 从不 |
|---|---|---|---|---|
| 修复前 | 0.314 | 0.584 | 0.925 | 0.925 |
| 修复后 | 0.309 | 0.309 | 0.309 | 0.309 |

（每 720 次使用一次时修复后为 0.205 / 0.204 / 0.198 / 0.196，残差即时代修正；
`verify.py §3.2`。）

**注.** 定理要求成熟度轨迹相同。生命周期晋升只在 reflect 中评估，因此"何时晋升"
仍取决于 reflect 频率，进而改变半衰期 $H_m$。这是当前唯一残留的调度依赖（§13）。

### 3.3 噪声与遗忘

**命题 3.3（六次确认阈值）。** 无否证时，证据地板的时刻零值
$f(n, 0, 0) = \phi_{\max}\frac{n+1}{n+2}\big(\frac{n}{n+10}\big)^2$ 关于 $n$ 严格递增，且

$$
f(n, 0, 0) < \theta_{\text{fade}} \iff n \le 6 .
$$

*证明.* 三个因子都关于 $n$ 递增。直接计算：$f(6) = 0.35 \cdot \tfrac78 \cdot (\tfrac{6}{16})^2 = 0.0431$，
$f(7) = 0.35 \cdot \tfrac89 \cdot (\tfrac{7}{17})^2 = 0.0527$。$\square$

**推论 3.4（一次性提及的命运）。** 首次提及后 $c_1 = 0.2056$，$f \approx 0.0019$，
$H = 24$。闲置 $\tau$ 次观察后 $c = f + (c_1 - f)2^{-\tau/24}$，因此

- 在 $\tau_{\text{fade}} = 24 \log_2\frac{c_1 - f}{0.05 - f} = 50.0$ 次观察后标记为 fading；
- 在 $24 \log_2\frac{c_1 - f}{0.02 - f} = 83.9$ 次后低于剪枝阈值 0.02；
- 因剪枝宽限期（闲置 ≥ 720），在第 **720** 次观察被删除。

三个数值与引擎逐步模拟一致（`verify.py §3.3`）。反过来，被确认 $n \ge 7$ 次的概念
在不被否证时不会因闲置而进入 fading，直到时代项把地板降到阈值以下：
$\tau \ge \mathcal{E}\log_2\big(f(n,0,0)/\theta_{\text{fade}}\big)$（$n=30$ 时约 8 450 次观察）。

**命题 3.5（复现路径的节律界）。** 设概念以固定节律 $T$（$24 \le T$）被使用，且每次
都落在不同的 24-tick 窗口。若

$$
T < T^{*} = \mathcal{E}\log_2\frac{\phi_{\max}}{0.3} \approx 974,
$$

则它最终满足复现晋升条件（复现 ≥ 10 且置信度 ≥ 0.3）并成为 established。

*证明.* 由结算的定义，结算后 $c \ge f$；使用只会增加 $c$。在下一次使用之前，
$\tau \le T$，故 $c \ge \phi_{\max}\frac{n+1}{n+2}(\frac{n}{n+10})^2 2^{-T/\mathcal{E}}$。
当 $n \to \infty$ 时右端趋于 $\phi_{\max}2^{-T/\mathcal{E}}$，它大于 0.3 当且仅当 $T < T^*$。
复现次数随使用线性增长，必然超过 10。developing 阶段的条件（复现 ≥ 3 且置信度 ≥ 0.15）
同理被满足。$\square$

这是一个**充分条件**，也是一个诚实的负面结论：它保证可达，但不保证快。实测
（`verify.py §3.4`）：$T = 168$ 需要 27 次使用；$T = 720$ 需要 324 次使用，
即约 23 万次观察。稀疏节律下 established 在实践中不可达，这一点此前的分析文档
没有指出。

### 3.4 证据与显著性

**定义 3.4（证据与显著性，`ConceptNode.evidence`、`ConceptNode.salience`）。**

$$
e(n, d) = \frac{n+1}{n+d+2}\cdot\frac{n}{n+10}, \qquad
s(\tau) = \max\Big(\underbrace{\max\big(0.1,\ 2^{-\tau/168}\big)}_{\text{新鲜度}},\ \ 0.7\, e\, 2^{-\tau/\mathcal{E}}\Big).
$$

$e$ 与时间无关（"它是真的吗"），$s$ 与时间有关（"它现在在场吗"）。

**命题 3.6.** (i) $e$ 关于 $n$ 严格递增、关于 $d$ 严格递减，取值于 $[0,1)$；
(ii) $s \in [0.1, 1]$；(iii) 被确认 $n$ 次后闲置的概念，其显著性高于新鲜度下限 0.1 的
时间为 $\mathcal{E}\log_2(7e)$。$n = 50$ 时为 11 021 次观察，而一次性提及
（$e \approx 0.06$，$0.7e < 0.1$）从不高于下限。

*证明.* (i) 两个因子关于 $n$ 递增、第一个关于 $d$ 递减。(ii) 两项都在 $[0,1]$ 中，第一项
$\ge 0.1$。(iii) 解 $0.7 e\, 2^{-\tau/\mathcal{E}} = 0.1$。$\square$

## 4. 关系动力学

### 4.1 三种证据

关系有三个量，由三种证据分别驱动（`schemas/relation.py`）：

| 量 | 被什么改变 | 不被什么改变 |
|---|---|---|
| 操作权重 $w_e$、结构置信度 $k_e$ | 强化（显式重述或共现）、否证、时间 | — |
| 语义概率 $p_e$ | 显式确认、否证、抽取给出的概率 | **时间** |

强化：显式边 $w \leftarrow \min(1, w + 0.08/(1 + 0.05 r))$；共现边
$w \leftarrow \min(0.7, w + 0.06/(1 + 0.15 r))$。因此**共现边的权重永远不超过 0.7，
显式边可达 1**。显式边以其语义类型的传播强度为初始权重与概率，共现边以 0.15 起步。

**命题 4.1（确认的闭式，`RelationEdge.confirm`）。** 第 $k$ 次无附带概率的显式确认后

$$
p_k = 1 - (1 - p_0)\,0.95^{k}.
$$

*证明.* $1 - p_{k+1} = (1 - p_k)(1 - 0.05)$。$\square$

例：$p_0 = 0.70$ 经 20 次确认到 0.8925。

**命题 4.2（语义概率不随时间变化）。** 结算算子 $\mathsf{Settle}$ 不改变 $p_e$。

*证明.* `settle_relation` 只写 $w_e$、$k_e$ 与结算时刻。$\square$

这是一个设计选择而非推论："时间流逝不是反对一条关系的证据，只是反对它当前显著性
的证据"。

### 4.2 存续

**定义 4.1（关系结算，`decay.settle_relation`）。** 半衰期 $H^r = 72(1 + 0.5 r_e)$；
显式边的地板 $f^r = \eta\, p_e\, 2^{-\tau/\mathcal{E}}$（$\tau$ 为距最近强化的时间），共现边地板为 0。
$w$ 与 $k$ 以与定义 3.3 相同的方式向 $f^r$ 松弛。权重低于 0.02 的关系在 reflect 时被剪枝。

**命题 4.3（显式关系的存续下界）。** 若显式关系在最近一次强化后未被否证，则它
至少存续

$$
T_{\text{keep}} \;\ge\; \mathcal{E}\log_2(5\,p_e)
$$

次闲置观察才可能被剪枝。

*证明.* 以类型默认值创建时初值 $w = p_e$（传播强度）$\ge \eta p_e = f^r(0)$；强化只增加 $w$，结算保持
$w \ge f^r$（由 $f^r$ 单调不增，与命题 3.1 相同的归纳）。故只要
$f^r = 0.1\,p_e\,2^{-\tau/\mathcal{E}} \ge 0.02$，就有 $w \ge 0.02$。解出 $\tau$ 即得。$\square$

**注（负向主张不受保护）.** 当 $p_e < 0.2$ 时下界为负，即地板从一开始就低于剪枝
阈值。负向关系的类型默认概率只有 0.05–0.12（`conflict` 0.10、`disjointness` 0.05），
因此一个只陈述过一次的负向主张**不受**关系地板保护，会像共现边一样因闲置被剪除。
这是 PR 中列为未决的"负向主张初始信念偏低"在存续上的精确后果。

**注（上界与滞后）.** 地板在移动，而 $w$ 以半衰期 $H^r$ 追随它，因此存在滞后：
连续结算时 $w - f^r \approx f^r H^r/\mathcal{E}$，存续时间趋于
$\mathcal{E}\log_2\big(5p_e(1 + H^r/\mathcal{E})\big)$。滞后随结算频率变化，幅度受命题 3.1 的
修正项约束。实测（每 50 次观察结算一次）：$p = 0.70$ 下界 7 916，实际 8 100；
$p = 0.768$（五次重述）下界 8 501，实际 9 200（`verify.py §4.2`）。

### 4.3 对立主张

**定义 4.2（对立，`RelationEdge.opposes`）。** 两个主张对立，当且仅当二者都不是
`generic_relation`，且恰有一个在 negative 轴上。

**命题 4.4（对立是对称关系）。** 对任意语义关系 $\sigma_1, \sigma_2$，
$\sigma_1$ 与 $\sigma_2$ 对立 $\iff$ $\sigma_2$ 与 $\sigma_1$ 对立。

*证明.* 定义中的两个条件都关于交换对称。$\square$

这个显然的命题在修复前**不成立**（§12，F2）：代码只检查被削弱一方是否为
`generic_relation`，于是一句"A related_to B"会削弱已有的"A conflict B"，反过来则不会。
`verify.py §4.3` 对全部 $26^2 = 676$ 个有序语义对检验了对称性。

摄入一个显式主张时，同一概念对上与之对立的显式主张各被否证一次
（$p \leftarrow \max(0.01,\ p - 0.06/(1 + 0.1\delta))$）。因此两组对立陈述会相互竞争，
而不是双双保持高置信度；共现边与 `generic_relation` 不参与。

## 5. 共现学习（Hebbian）

一对未联结的概念在同一观察中共现时，待定计数加一；当计数 $\ge 2$ **且**关联
$J \ge \theta_J = 0.2$ 时，创建一条 `generic_relation` 共现边。

**定义 5.1（关联，`HebbianEngine._association`）。**

$$
J(a,b) = \frac{C(a,b)}{n(a) + n(b) - C(a,b)},
$$

即提及 $a$ 或 $b$ 的观察中，同时提及二者的比例（观察集合上的 Jaccard 系数）。

**引理 5.1（Jaccard 是两个条件概率的函数）。** 令 $\hat P(b \mid a) = C/n(a)$，
$\hat P(a \mid b) = C/n(b)$，则

$$
J = \Big(\frac{1}{\hat P(b\mid a)} + \frac{1}{\hat P(a\mid b)} - 1\Big)^{-1}.
$$

*证明.* 分子分母同除以 $C$。$\square$

因此关联门是对两个方向条件概率的**联合**要求：任一方向很弱都会拉低 $J$，这正是
"枢纽概念不与偶然相遇者联结"的机制。

**推论 5.2（对称阈值）.** 若 $\hat P(b\mid a) = \hat P(a\mid b) = \rho$，则
$J = \rho/(2 - \rho)$，而

$$
J \ge \theta_J \iff \rho \ge \frac{2\theta_J}{1+\theta_J} = \frac13 .
$$

**命题 5.3（两种世界的渐近关联）。**

(i) *独立提及。* 若 $a$、$b$ 以概率 $q_a$、$q_b$ 独立出现在每次观察中，则几乎必然
$J \to \dfrac{q_a q_b}{q_a + q_b - q_a q_b}$；对称时为 $q/(2-q)$。

(ii) *话题结构。* 若每次观察从某个大小为 $m$ 的话题中无放回抽取 $k$ 个概念（话题
以概率 $\pi$ 被选中），则同话题的两个概念满足 $\rho = \frac{k-1}{m-1}$，
$J \to \rho/(2-\rho)$，**与话题频率 $\pi$ 无关**。

*证明.* (i) 由强大数定律，$C/N \to q_a q_b$、$n(\cdot)/N \to q_\cdot$，代入定义 5.1 并由
连续映射定理即得。(ii) $P(a \in o) = \pi k/m$，$P(a, b \in o) = \pi\frac{k(k-1)}{m(m-1)}$，
比值为 $\rho$，$\pi$ 被约去；再用推论 5.2。$\square$

数值：60 个概念每次随机取 6 个时 $q = 0.1$，$J_\infty = 0.0526$（模拟 0.035–0.055），
远低于门槛；6 个概念的话题每次取 4 个时 $\rho = 0.6$，$J_\infty = 0.4286$（模拟
0.41–0.44），远高于门槛。这解释了第八轮扫描中"随机蔓延 85 % → 9 %、同话题 100 %"
的结果，且说明它不依赖于话题出现的频率。

**关联门需要门槛计数的原因.** 早期统计很薄：两次提及、两次都在一起，$J = 1$。
因此 reflect 会用累积统计重新审查共现边（`HebbianEngine.revalidate`）：当两端的提及
合计 ≥ 20 且 $J < \theta_J/2 = 0.1$ 时移除。

**命题 5.4（滞回无振荡）。** 若提及统计平稳，使得 $J_t \to J_\infty$ 且
$J_\infty \notin \{0.1, 0.2\}$，则一对概念的联结状态最终不再改变。

*证明.* 若 $J_\infty > 0.2$：最终 $J_t > 0.2 > 0.1$，已联结的不会被移除，未联结的在下次
共现时被联结。若 $J_\infty < 0.1$：最终不会被创建，已有的在下次 reflect 被移除。若
$0.1 < J_\infty < 0.2$：最终既不满足创建条件也不满足移除条件，状态冻结在当时的值。
三种情况都只有有限次改变。$\square$

**关于计数的精确性（§12，F3）.** 命题 5.4 要求 revalidate 看到的是真实的 $C(a,b)$。
修复前它用"强化次数 + 2"估计，这只在边恰好在第 2 次共现时创建才准确；关联门推迟
了创建时，估计值偏低。实测中真实共现 8 次、估计 4 次，关联从 0.25 被低估到 0.11，
几乎落到移除线上。第十八轮之后引擎为已联结对保存了精确计数，现在 revalidate 取
二者的较大值（旧存储仍回退到估计值）。

## 6. 扩散激活

### 6.1 聚合：有界 noisy-OR

**定义 6.1（`activation._accumulate`）。** 设 $S > 0$ 为最强种子的分数。对
$a, b \ge 0$，令 $\bar a = \min(1, a/S)$，$\bar b = \min(1, b/S)$，

$$
a \oplus_S b = S\big(\bar a + \bar b - \bar a\bar b\big) = S\big(1 - (1-\bar a)(1-\bar b)\big).
$$

**命题 6.1.** 在 $[0, S]$ 上，$\oplus_S$ 是以 0 为单位元的 t-余模（概率和的缩放）：
交换、结合、单调；并且

$$
\max(a,b) \le a \oplus_S b \le S,\qquad 0 < a, b < S \Rightarrow a \oplus_S b > \max(a,b).
$$

对任意 $a, b \ge 0$（包括超过 $S$ 的单路贡献），结果仍 $\le S$。

*证明.* 归一化后是概率和 $x + y - xy = 1 - (1-x)(1-y)$，它的交换、结合、单调、以 0 为
单位元都是标准性质。$1-(1-x)(1-y) \ge 1-(1-x) = x$；当 $0 < x, y < 1$ 时不等号严格。
截断保证 $x, y \le 1$，故结果 $\le 1$，乘以 $S$ 即得。$\square$

这一命题有两个运行上的推论：从两个种子**汇聚**到的概念严格高于只从一个种子到达
的概念（第一轮缺陷 C 修复的正是这一点）；聚合结果与路径到达的顺序无关（结合律）。

### 6.2 传播与秩保持地板

一条从已激活概念 $u$（分数 $a_u$，位于第 $j$ 层）到邻居 $v$ 的非负边贡献

$$
x_{uv} = a_u \cdot \underbrace{w_e\, \omega_P(e)\, \omega_{\text{dir}}(e)}_{\text{边强度}} \cdot \underbrace{\max(c_v, e_v, 0.3)}_{\text{就绪度}} \cdot \delta^{\,j+1} \cdot \gamma_{\text{task}}\, \gamma_{\text{dom}} \cdot \underbrace{\max\!\big(0.15, 2^{-\tau_e/(72(1+0.5r_e))}\big)}_{\text{关系新鲜度}} \cdot s_v ,
$$

其中 $\omega_P$ 是视角对该语义关系 / 轴的权重，$\omega_{\text{dir}}$ 只作用于有向边，
$\gamma_{\text{task}} \in [1, 1.5]$、$\gamma_{\text{dom}} \in \{1, 1.3\}$，$\delta$ 是深度衰减（`World.project`
默认 0.5）。negative 轴的边以同样的乘积（乘以 0.6）进入独立的抑制通道。

**定义 6.2（秩保持地板，`ActivationEngine._apply_floor`）。** 令 $F = 0.03\,S$，

$$
\varphi(x) = \begin{cases} x, & x \ge F,\\ F\,(0.9 + 0.1\,x/F), & 0 < x < F. \end{cases}
$$

**命题 6.2.** $\varphi$ 在 $(0, \infty)$ 上连续且严格递增，把 $(0, F)$ 映到 $(0.9F, F)$。

*证明.* 两段都是正斜率的仿射函数（斜率 0.1 与 1），在 $x = F$ 处两段取值都是 $F$。$\square$

这是对第一轮缺陷 D（常数地板把深层节点压成同分）的形式化：弱信号被抬升进一条
窄带，但彼此的顺序保留。

### 6.3 主要性质

**定理 6.3（种子支配）。** 设 $S$ 为种子分数的最大值。对任何非种子概念 $v$，
其净激活 $a(v) - i(v) \le S$。每个种子都出现在激活结果中，分数为
$\max(0,\ s - i(s))$。

*证明.* 非种子概念的激活只能由某一层的 $\oplus_S$ 累加写入（命题 6.1：$\le S$），抑制非负，
故净值 $\le S$。种子的深度为 0，而兴奋只流向深度更大的层，所以种子的激活值从不
被覆盖。结果中保留种子是 §12 F1 修复后的行为。$\square$

**定理 6.4（视界完备性）。** 设种子 $u$ 的分数 $s_u \ge \text{cut} = \min(0.01, 0.02S)$。
若概念 $v$ 与 $u$ 之间存在一条长度 $\le D$ 的路径，路径上每条边都是非负轴、权重为正、
视角权重为正，则 $v$ 的兴奋激活 $\ge 0.027\,S$。因此 $v$ 出现在结果中，除非它被抑制到
cut 以下。

*证明.* 对层数归纳，证明路径上第 $j$ 个概念要么已在更浅的层被激活，要么在第 $j$ 层
获得 $\ge 0.027S$ 的兴奋。第 $j$ 层的源分数 $\ge 0.027S > 0.02S \ge \text{cut}$，因此会被展开；
贡献 $x > 0$，因为每个因子都为正（就绪度 $\ge 0.3$，关系新鲜度 $\ge 0.15$，显著性 $\ge 0.1$）。
由命题 6.2，$\varphi(x) \ge \min(x, 0.9F)$；而当 $x < F$ 时 $\varphi(x) \ge 0.9F = 0.027S$，
当 $x \ge F$ 时 $\varphi(x) = x \ge F$。两种情况都 $> \text{cut}$，因此被写入该层，又由命题 6.1
$\oplus_S$ 不减少。$\square$

这给出了"地板把认知视界从 1 跳扩展到 3–4 跳"的精确版本：**在给定深度内，视界
是完整的**，任何经非负边可达的概念都不会因乘积链变小而丢失。视界的边界由 $D$ 和
视角权重（权重为 0 即切断）决定，而不是由乘积的数值下溢决定。

**命题 6.5（终止性与代价）。** 激活至多执行 $D$ 层；每个概念至多被赋予一次深度、
至多展开一次；每条关系至多从两端各扫描一次。设被触及的子图为 $(V_D, E_D)$，
单次激活的代价为 $O\big((|V_D| + |E_D|)\cdot \bar\pi\big)$，$\bar\pi \le 64$ 是任务画像的大小。

*证明.* 一个概念被写入第 $j+1$ 层后深度为 $j+1$；此后在第 $j' \ge j+1$ 层处理时，条件
"深度 $\le j'$"使它被跳过，故它只进入一次前沿。每个前沿成员只扫描自己的邻接表一次，
因此每条边至多扫描两次。每条边上的主要附加开销是任务亲和度查询，代价与画像大小
成正比。$\square$

## 7. 投影

### 7.1 相关性

对候选 $v$（激活不低于 cut，或者是种子），投影计算

$$
\mathrm{rel}(v) = \frac{a(v)}{a_{\max}} \cdot \underbrace{\big(0.6 + 0.4\,\alpha_v\big)}_{\tau_v} \cdot \underbrace{\big(0.7 + 0.3\,s_v\big)}_{\phi_v} \cdot \big(1 + \gamma\, \psi_v\big),
$$

其中 $\alpha_v = \max(\text{历史亲和},\ \text{词面锚定})$ 是任务亲和度，$s_v$ 是显著性，
$\psi_v \in [0, 1]$ 是焦点亲和度（未开启持续注意时为 0）。选择时先放入种子，再以

$$
\operatorname{mmr}(v) = (1 - \lambda)\,\mathrm{rel}(v) - \lambda\,\mathrm{red}(v),
\qquad \mathrm{red}(v) = \begin{cases} \max\big(\mathrm{sim}(v),\ 1 - \alpha_v\big), & 1-\alpha_v > \mu, \\ \mathrm{sim}(v), & \text{否则}, \end{cases}
$$

（已选集合为空时 $\mathrm{red} \equiv 0$，第一个位置只按相关性选取。）

贪心填充其余位置。这里 $\mathrm{sim}(v)$ 是 $v$ 与已选概念之间邻居集合 Jaccard 相似度的最大值，
$\mu$ 是剩余候选中最小的任务失配度。

**命题 7.1（种子优先）。** 设 $\Sigma$ 为能解析到的种子集合，则投影包含 $\Sigma$ 中按分数
排列的前 $\min(|\Sigma|, K)$ 个。

*证明.* 由定理 6.3，每个种子都在激活结果中；投影的候选过滤对种子豁免；选择在 MMR
之前先放入种子。$\square$

修复前这个命题只对"激活后仍高于 cut 的种子"成立（§12 F1）：一个已褪色的种子
（置信度 0.004，另一个种子 0.9）在激活的净值截断中被丢弃，投影的豁免根本看不到它。

**命题 7.2（有界性）。** $\tau_v \in [0.6, 1]$，$\phi_v \in [0.73, 1]$，焦点乘子 $\in [1, 1.5]$，
$\mathrm{red} \in [0,1]$。特别地，任务亲和度至多使相关性相差 $1/0.6$ 倍，焦点至多使其
放大 1.5 倍。

**命题 7.3（离题候选等价于完全冗余）。** 若剩余候选中存在更贴合任务的（$1 - \alpha_v > \mu$），
则 $\mathrm{red}(v) \ge 1 - \alpha_v$；特别地，与任务毫无关联的候选（$\alpha_v = 0$）满足
$\mathrm{red}(v) = 1$，与一个邻居集合完全重合的重复项无法区分。离题候选 $x$ 胜过最贴合的
候选 $y$，当且仅当

$$
(1-\lambda)\big(\mathrm{rel}(x) - \mathrm{rel}(y)\big) > \lambda\big(\mathrm{red}(x) - \mathrm{red}(y)\big).
$$

*证明.* 由 $\mathrm{red}$ 的定义直接得出；最后一式是 $\operatorname{mmr}(x) > \operatorname{mmr}(y)$ 的改写。$\square$

这形式化了第九轮的修复：修复前"多样性"项会奖励一个仅与种子相邻、因此看起来
"不冗余"的离题概念，让它挤掉同话题的概念；现在离题本身就算作冗余，只有当它的
相关性优势大到足以抵消这一差距时才能入选。

**命题 7.4（无任务时退化为经典 MMR）。** 任务为空时 $\tau_v \equiv 1$、$\mu = 0$、失配度
$\equiv 0$，锚定为空，选择规则退化为以 $\frac{a}{a_{\max}}\phi(1+\gamma\psi)$ 为相关性、以邻居
Jaccard 为冗余的 MMR。

### 7.2 词面锚定

**定义 7.1（`context/grounding.py`）。** 设任务的词集为 $T$，概念名（或别名）的词集为
$N$，覆盖度为 $\kappa = |N \cap T|/|N|$（对没有签名词的名称，退化为整串包含：包含得 1，
否则得 0）。锚定亲和度 $g(v)$ 的定义是：若 $\kappa_v \ge 0.5$，则 $g(v) = \kappa_v$；否则，若 $v$ 与某个 $\kappa = 1$ 的
锚点相邻，则 $g(v) = 0.5$；否则 $g(v) = 0$。

**命题 7.5.** (i) $g \in \{0\} \cup [0.5, 1]$；(ii) 若任务没有覆盖任何候选名称的一半以上，
则 $g \equiv 0$，投影与只用历史亲和时完全相同；(iii) 单调性：若 $T \subseteq T'$，则
逐点有 $g_T \le g_{T'}$。再加上 $\alpha = \max(\text{历史}, g)$，**词面锚定永远不会降低任何
候选的任务亲和度**。

*证明.* (i)、(ii) 由定义直接得出。(iii) 覆盖度关于 $T$ 单调，因此在 $T$ 下的锚点在 $T'$
下仍是锚点，直接覆盖的值也不减。$\square$

**命题 7.6（确定性）。** 给定存储状态、时钟 tick 与墙钟时刻，投影是确定的函数：
候选按（分数降序，id）的顺序访问，关系按（权重降序，id）排序，同分时按 id 决出。
不依赖 `PYTHONHASHSEED` 或文件加载顺序。

## 8. 持续焦点（全局工作空间）

**定义 8.1（`context/focus.py`）。** 焦点是一个映射 $\mathcal{F}$：概念 → 强度 $\in (0,1]$。
每次投影后按下面的更新 $U$ 演化：

$$
\mathcal{F} \leftarrow \operatorname{top}_7\Big(\{v \mapsto 0.6\,\mathcal{F}(v) : 0.6\,\mathcal{F}(v) \ge 0.15\} \ \cup\ \{v \mapsto 1 : v \in \text{Ign}\}\Big),
$$

其中点燃集 $\text{Ign}$ 由两部分组成：全部种子，以及相关性不低于本视图最强非种子相关性一半的
已选概念。焦点亲和度对候选 $v$ 的定义是：

$$
\psi_v = \max\Big(\mathcal{F}(v),\ \max_{u \in N(v)\setminus \Sigma} 0.5\,\mathcal{F}(u)\Big)
$$

这里本次投影的种子 $\Sigma$ 不向邻居传递亲和。显式任务改变时焦点被清空。

**命题 8.1（容量与寿命）。** (i) $|\mathcal{F}| \le 7$ 恒成立。(ii) 一个只被点燃一次的
概念，如果没有被容量挤出，恰好在其后 $L = \lfloor \ln 0.15/\ln 0.6 \rfloor = 3$ 次更新中保留
（强度依次为 0.6、0.36、0.216），在第 4 次更新时离开（0.1296 < 0.15）。

*证明.* (i) 由 $\operatorname{top}_7$ 得出。(ii) 第 $j$ 次更新后强度为 $0.6^j$，保留当且仅当
$0.6^j \ge 0.15$。$\square$

**命题 8.2（只偏置，不注入）。** 对任意焦点状态，投影选出的概念集合是同一个候选集合的
子集，而这个候选集合与焦点无关（由激活决定）。

*证明.* 焦点亲和度只对候选计算，并且只进入相关性的乘子；候选的定义不含 $\mathcal{F}$。$\square$

**命题 8.3（有界偏置与无固着）。** 焦点使候选的相关性至多放大 1.5 倍；种子不传递
亲和；若新一轮的种子与焦点内容不相邻，则 $\psi \equiv 0$，投影与没有焦点时完全相同。

命题 8.1–8.3 共同说明：焦点是一个**有界、易逝、非注入**的注意状态，而不是记忆。
它无法让 Agent "看见"本轮激活没有触及的概念，也无法无限期地保留一个话题。

## 9. 预测误差

**定义 9.1（`HebbianEngine.prediction_error`）。** 在学习本次观察之前，对观察中每个被
提及 $\ge 5$ 次的概念 $a$、它的每个已联结伙伴 $b$，令 $p = C(a,b)/n(a)$；$p \ge 0.5$ 时记为
一条预测。设全部预测为 $\{p_j\}$，$X = \sum_{j:\,b_j \notin o} p_j$ 为缺席的预测质量，

$$
M = \sum_j p_j,\qquad V = \sum_j p_j(1-p_j),\qquad
\varepsilon_{\text{miss}} = \operatorname{clip}_{[0,1]}\frac{X - V}{M - V} = \operatorname{clip}_{[0,1]}\frac{X - V}{\sum_j p_j^2}.
$$

对观察中每一对支持度都 $\ge 5$ 但从未共现的概念，令 $\lambda_{ab} = n(a)n(b)/N$，
新组合度 $\varepsilon_{\text{nov}}$ 为 $1 - e^{-\lambda_{ab}}$ 在全部"已知对"上的平均。最终的意外度为
$\varepsilon = \max(\varepsilon_{\text{miss}}, \varepsilon_{\text{nov}})$。

**命题 9.1（取值与极值）。** $\varepsilon_{\text{miss}} = 1 \iff X = M$（全部预测缺席）；
$\varepsilon_{\text{miss}} = 0 \iff X \le V$。

*证明.* $X \le M$，且 $M - V = \sum p^2 > 0$。$\square$

**定理 9.2（在模型自身假设下的标定）。** 设在给定预测者出现的条件下，每个伙伴
$b_j$ 以其预测概率 $p_j$ 独立出现。则

$$
\mathbb{E}[X] = V, \qquad
\mathbb{E}[\varepsilon_{\text{miss}}] \;\le\; \frac{1}{2}\,\frac{\sqrt{\sum_j p_j^3(1-p_j)}}{\sum_j p_j^2}.
$$

*证明.* $X = \sum_j p_j \mathbb{1}[b_j \notin o]$，$\mathbb{E}\,\mathbb{1}[b_j\notin o] = 1-p_j$，得
$\mathbb{E}X = V$；同理 $\operatorname{Var}X = \sum_j p_j^2\,p_j(1-p_j)$。令 $Z = X - V$，则 $\mathbb{E}Z = 0$，
于是 $\mathbb{E}\max(0,Z) = \tfrac12\mathbb{E}|Z| \le \tfrac12\sqrt{\operatorname{Var}Z}$（Jensen）。
由于 $\varepsilon_{\text{miss}} \le \max(0, Z)/\sum p^2$，结论成立。$\square$

这个定理说明了第十八轮的标定为什么有效：原始的"缺席比例"把模型自己预期的波动
也记为误差，而减去 $V$ 之后，分子在模型正确时是**无偏**的，误差只剩下与预测数量
相关、可以界定的噪声。例：4 个 $p = 0.6$ 的伙伴时上界为 0.204，蒙特卡罗值为 0.173；
10 个 $p = 0.7$ 时上界为 0.104，实测为 0.081（`verify.py §9`）。上界随预测数 $n$ 按
$\tfrac12\sqrt{(1-p)/(np)}$ 衰减：伙伴越多，误差信号越干净。

**命题 9.3（新组合权重的含义）。** 在独立提及、提及率分别为 $q_a = n(a)/N$、$q_b = n(b)/N$
的零假设下，$N$ 次观察中两者从未共现的概率为 $(1 - q_a q_b)^N \le e^{-\lambda_{ab}}$。
因此，权重 $1 - e^{-\lambda_{ab}}$ 是"它们本应已经相遇"这一概率的**下界**，换言之是
"从未相遇"这一事件 p 值上界的补。

*证明.* $\ln(1-x) \le -x$。$\square$

例：各占一半历史（$n = 50$，$N = 100$）却从未相遇，权重为 1.000；两个都很少出现的概念
（$n = 5$，$N = 1000$），权重仅为 0.025。

**估计量.** $p = C(a,b)/n(a)$ 是 $P(b\mid a)$ 的最大似然估计；$C(a,b)$ 是自追踪开始以来的
精确共现数（待定计数在联结时迁入）。独立性假设是理想化：同一对概念会被双向预测
两次（$a \to b$ 与 $b \to a$），多个伙伴之间也可能相关。定理 9.2 的上界在这些情况下
不再严格，但分子的无偏性只依赖每条预测自身的边际概率，仍然成立。

## 10. 元认知

**命题 10.1（可靠性分级的计数刻画）。** 无否证时（$d = 0$），

$$
e(n) < 0.15 \iff n \le 2, \qquad e(n) \ge 0.5 \iff n \ge 12 ,

即"暂定"（tentative）恰为被提及至多 2 次的概念，"证据充分"（well-evidenced）恰为

contested，否则标为 leaning。由命题 4.4，报告与主张陈述的先后顺序无关。

## 11. 复杂度

记 $k$ 为一次观察中的概念数、$\deg$ 为平均度、$K$ 为投影大小、$C$ 为候选数。

| 操作 | 代价 | 说明 |
|---|---|---|
| 摄入 | $O(k \cdot \ell + \min(k^2, 30) + \sum_{a \in o}\deg(a))$ | $\ell$：身份解析的候选名单长度（第三轮索引）；共现对上限 30；预测遍历被观察概念的邻居 |
| 结算（单个） | $O(1)$ | 使用前的惰性结算不改变摄入的渐近代价 |
| 激活 | $O((|V_D| + |E_D|)\,\bar\pi)$ | 命题 6.5 |
| 投影 | $O(C\,\deg + K\cdot C\cdot K\cdot \deg)$ | 邻居集合与 MMR 的逐对 Jaccard；$C$ 受激活截断约束 |
| reflect（轻） | $O(|V| + |E|)$ | 全体结算、生命周期、剪枝、revalidate |

实测（第十二、十八轮）：2 000 个概念时每次观察约 1.6 ms，投影约 0.4 ms。

## 13. 局限与未证明的部分

- **常数没有被推导。** 半衰期、阈值、增益都是标定出来的；本文只推导它们的推论。
  特别地，命题 3.5 表明稀疏节律（$T \gtrsim 500$）下 established 实际不可达，而这是否
  是想要的行为，是一个设计问题，不是数学问题。
- **成熟度的调度依赖。** 定理 3.2 以成熟度轨迹相同为前提。晋升只在 reflect 时评估，
  因此晋升的时刻（进而影响半衰期）仍取决于 reflect 的频率。一个自然的修复是在结算时
  顺带评估生命周期；但晋升条件中的连接数需要读取关系存储，会把生命周期引擎耦合进
  概念管理器，本文暂不处理。
- **独立性假设。** 命题 5.3、定理 9.2、命题 9.3 都依赖独立或平稳假设。真实的观察流
  既不独立也不平稳（这正是概念漂移）。它们说明的是"在零假设下系统不会误报"，而
  不是"在真实数据上的精确误报率"。
- **MMR 没有近似保证。** 贪心 MMR 在一般情况下没有子模性保证；任务冗余项
  $\max(\mathrm{sim}, 1 - \alpha)$ 还会破坏目标函数的某些结构。本文只证明了它的局部性质
  （命题 7.3、7.4），没有证明全局最优性。
- **未覆盖的子系统。** 社群检测与色场动力学（`dynamics/community.py`、
  `dynamics/color_diffusion.py`）不在本文范围内；它们只影响 reflect 的重型步骤与
  领域亲和度，不影响本文的任何命题。
- **墙钟漂移。** 新鲜度含墙钟项（每小时 0.1 tick），因此投影在两次调用之间可以因为
  真实时间流逝而发生微小变化。命题 7.6 的确定性是以墙钟时刻为参数的。
