## 摘要

World 0 是一个面向 LLM Agent 的概念世界认知层：概念与带类型的关系构成一张图，
观察流在其上引起强化、共现学习与遗忘，任务条件下的扩散激活与多样性选择从中
投影出一个小的局部视图。本文给出该系统当前实现的完整形式模型，并对其动力学与
算法性质给出证明。主要结果包括：

1. **时间**：以观察次数为单位的认知时钟下，概念与关系的结算都是移动地板松弛方程的精确解，因而是精确半群
   （命题 3.1、4.2′），褪色边界也是精确的（命题 3.1′）；配合"使用前结算"，遗忘量与反思（reflect）的调用
   频率无关（定理 3.2）；成熟度的晋升门只含在事件上变真的量并在事件上评估，"已死"的概念与关系在事件上按结算后
   状态判定并被当作不存在（惰性回收，定义 3.6），于是（存在性、成熟度、置信度）整条轨迹与 reflect 频率无关
   （定理 3.7）。节律 $T \le 720$ 的稀疏使用在第 12 次成为 established（命题 3.5）；更稀疏的使用在积累到
   7 次确认之前就被当作噪声遗忘。
2. **证据与噪声**：被确认不超过 6 次的概念，其证据地板低于褪色阈值，必然被遗忘；
   第 7 次确认起地板越过阈值（命题 3.3）。可靠性分级、显著性持续时间、关系存续
   时间均有闭式（命题 3.6、4.3、10.1）。
3. **共现学习**：Jaccard 关联恰是两个条件概率的调和型组合
   $J = (1/P(b\mid a) + 1/P(a\mid b) - 1)^{-1}$（引理 5.1），因此阈值 0.2 在对称情形下
   等价于 $P(b\mid a) \ge 1/3$；独立噪声的渐近关联为 $q/(2-q)$（命题 5.2）。
4. **激活**：有界 noisy-OR 是以最强种子分数 $S$ 为上界的 t-余模；任何被传播到的概念
   都不超过 $S$（定理 6.3）；秩保持地板使深度 $D$ 内经非负边可达的概念全部进入候选
   （定理 6.4）；一次激活的代价与被触及的子图大小成线性（命题 6.5）。
5. **投影与焦点**：种子总在投影中（命题 7.1）；与任务无关的候选在 MMR 中等价于完全
   冗余的重复项（命题 7.3）；持续焦点容量有界、单次点燃恰好保留 3 次投影、只偏置
   不注入（命题 8.1–8.3）。
6. **预测误差**：以模型自身的伯努利预测为零假设，缺席误差的分子无偏，期望误差有
   上界 $\tfrac12\sqrt{\sum p^3(1-p)}/\sum p^2$（定理 9.2）；新组合的权重是独立假设下
   "本应已相遇"概率的保守估计（命题 9.3）。

形式化过程本身发现了实现与设计意图不一致的七处缺陷（§12，F1–F7），其中最重要的
是：激活会移动衰减参照点，而此前在两次使用之间未结算的衰减被直接丢弃，导致遗忘
量取决于 reflect 的调用频率——同一概念在不同调用习惯下置信度可以是 0.31 或 0.93（F4）；
修复之后剩下的调度依赖先是成熟度：同一条观察流按 reflect 习惯可以终止于 core / established /
developing / embryonic（F6）；再是存在性：一个已经"死"的概念或关系在从不 reflect 的世界里会被一次提及复苏，
在 reflect 过的世界里却被新建（F7，由独立评审发现）。七处均已修复，并由回归测试固定。

## 1. 引言

World 0 的设计文档（`AGENTS.md`）用自然语言规定了系统应具备的性质：概念优先、
关系有类型、上下文改变相关性、投影是运行时输出、系统可逐步演化而不坍缩为语义
蔓延。前十八轮开发以探针（probe）驱动：先测量一个行为，发现缺陷，修复，再测量。
这种方法能发现"已经出错"的地方，但不能说明"为什么不会出错"。

本文的目标是后者：把当前实现中的每个算子写成数学对象，陈述它们应当满足的性质，
给出证明，并在代码上逐一数值检验。三点方法约定：

- **只陈述实现真正满足的性质。** 若证明需要某个前提（例如成熟度轨迹相同、独立
  性假设），前提会显式写出；若实现不满足某个"本应成立"的性质，就把它作为缺陷
  记录并修复（§12），而不是修改命题去迁就实现。
- **常数是给定的。** 半衰期、阈值等常数来自此前各轮的标定（分析文档 §5 及各节），
  本文不论证它们的最优性，只推导它们的推论（例如"6 次"、"3 次投影"、"12 次确认"
  这些由常数决定的临界值）。
- **可复现。** `python docs/paper/verify.py` 输出本文引用的全部数值。

## 2. 形式模型

### 2.1 世界状态

在认知时刻 $t \in \mathbb{N}$，世界状态为

$$
\mathcal{W}_t = (V_t,\ E_t,\ \Theta_t,\ \mathcal{F}_t),
$$

- $V_t$：概念集合。概念 $v$ 的动力学状态是
  $x_v = (c_v, m_v, n_v, d_v, t^{a}_v, t^{d}_v, \rho_v, \pi_v)$：置信度 $c_v\in[0,1]$、
  成熟度 $m_v \in \{\textsf{emb},\textsf{dev},\textsf{est},\textsf{core},\textsf{fad}\}$、
  确认次数 $n_v$、否证次数 $d_v$、最近激活时刻 $t^a_v$、最近结算时刻 $t^d_v$、
  复现窗口数 $\rho_v$、任务画像 $\pi_v$（任务标签 → 次数）。
- $E_t$：关系集合。关系 $e=(u\to w)$ 的状态是
  $y_e = (\text{axis}_e, \sigma_e, w_e, k_e, p_e, r_e, \delta_e, t^r_e, t^d_e, \chi_e)$：
  轴（positive / negative / parallel）、语义关系名 $\sigma_e$、操作权重 $w_e$、结构
  置信度 $k_e$、语义概率 $p_e$（"该类型关系正确"的信念）、强化次数 $r_e$、否证次数
  $\delta_e$、最近强化与结算时刻、是否显式声明 $\chi_e$。
- $\Theta_t$：学习统计（`dynamics/hebbian.py`）：观察数 $N$、提及数 $n(a)$、未联结对的
  待定共现数、已联结对的共现数 $C(a,b)$。
- $\mathcal{F}_t$：持续焦点（`context/focus.py`，可选）：至多 7 个概念及其强度。

概念的**证据**与**显著性**是状态的函数（§3.4），不是独立状态。

### 2.2 认知时钟

**定义 2.1（认知经过时间，`schemas/clock.py:cognitive_elapsed`）。** 两个时刻
$(t_1, h_1)$、$(t_0, h_0)$（观察计数与墙钟小时）之间的认知经过时间为

$$
\Delta\big((t_1,h_1),(t_0,h_0)\big) = \max(0,\ t_1 - t_0) + \beta \max(0,\ h_1 - h_0),
\qquad \beta = 0.1 .
$$

每次 `ingest()` 使 $t$ 加一；墙钟只作为闲置时的缓慢漂移（空闲一天约 2.4 个 tick）。

**命题 2.1（可加性）。** 对单调的三个时刻 $s_0 \le s_1 \le s_2$（两个分量都单调），
$\Delta(s_2, s_0) = \Delta(s_2, s_1) + \Delta(s_1, s_0)$。

*证明.* 单调时两个 $\max$ 都取第一项，两个分量各自是差分，可加。$\square$

可加性是 §3 半群性质的前提：遗忘只能是经过时间的函数，而经过时间必须可以任意
切分。下文把 $\Delta$ 简记为 tick 差。

### 2.3 算子

系统由五个算子驱动（`world/facade.py`）：

| 算子 | 触发 | 作用（按执行顺序） |
|---|---|---|
| $\mathsf{Ingest}(o)$ | 每次观察 | 时钟 +1 → 解析 / 创建概念 → **结算**、激活、**事件时晋升** → 显式关系（创建 / 强化时对两端评估 core）（发现 / 强化 + 确认 / 削弱对立主张） → **预测误差** → 共现学习 → 描述 → 否证 → 色场 |
| $\mathsf{Settle}_t(\cdot)$ | 每次强化之前；reflect 时对全体 | 把自上次结算以来欠下的衰减施加到置信度 / 权重上 |
| $\mathsf{Activate}(S)$ | 投影时 | 分层扩散激活，兴奋与抑制两通道 |
| $\mathsf{Project}(a)$ | 投影时 | 种子优先 + 任务感知 MMR，附元认知与注意轨迹 |

## 3. 概念动力学

### 3.1 增益

**定义 3.1（激活增益，`ConceptNode.activate`）。** 第 $n$ 次确认（$n$ 为确认后的计数）
使置信度增加

$$
b(n) = \frac{0.06}{1 + 0.08\,n}, \qquad c \leftarrow \min(1,\ c + b(n)).
$$

新概念以 $c_0 = 0.15$ 创建，并立即被确认一次，因此首次提及后 $c = 0.15 + b(1) \approx 0.2056$。

由于 $\sum_k b(k)$ 发散（调和级数），没有衰减时任意高的置信度都可达到：累计增益
$\sum_{k=1}^{N} b(k) \approx 0.75 \ln\frac{1+0.08N}{1.08}$，到达 0.6 需约 12 次（积分估计），
实际离散求和为 **11 次**（`verify.py §3.1`）。

### 3.2 结算：带地板的松弛

**定义 3.2（有效半衰期与证据地板，`decay.concept_half_life`、`decay.evidence_floor`）。**

$$
H(m, n) = \min\!\Big(H_{\max},\ H_m \cdot \min\big(s_{\max},\ 1 + g\,(n-1)^+\big)\Big),
$$

$$
f(n, d, \tau) = \phi_{\max}\cdot \frac{n+1}{n+d+2}\cdot\Big(\frac{n}{n+K}\Big)^{2} \cdot 2^{-\tau/\mathcal{E}},
$$

其中 $\tau$ 是距最近一次激活的认知时间。$\frac{n+1}{n+d+2}$ 是 Beta(1,1) 先验下确认 / 否证
的后验均值。

**定义 3.3（结算算子，`decay.settle_concept`）。** 设上次结算（或激活，取较晚者）在
时刻 $t_0$，当前时刻 $t_1$，$\Delta = t_1 - t_0 \ge 1$，$\lambda = \ln 2 / H(m,n)$，
$\mu = \ln 2/\mathcal{E}$。区间内地板按 $f(t) = f_0\,e^{-\mu (t-t_0)}$ 移动
（$f_0 = f(n, d, t_0 - t^a)$）。结算是初值问题

$$
\dot c \;=\; -\lambda\,\big(c - f(t)\big)^{+}, \qquad c(t_0) = c_0
$$

在 $[t_0, t_1]$ 上的**精确解**，并把参照点移到 $t_1$；$\Delta < 1$ 时跳过，参照点不动
（未施加的间隔不丢失）。显式解为：

- $c_0 \le f_0$：置信度不动，直到仍在下降的地板与它相遇（$t_x = \mathcal{E}\log_2(f_0/c_0)$），
  之后以 $c_0$ 为起点的地板按下一条继续；
- $c_0 > f_0$：$c(\Delta) = A e^{-\mu\Delta} + (c_0 - A)\,e^{-\lambda\Delta}$，
  $A = \lambda f_0/(\lambda - \mu)$；$\lambda = \mu$ 时为 $e^{-\lambda\Delta}(c_0 + \lambda f_0 \Delta)$。

这是向**移动目标** $f(t)$ 的 Ornstein–Uhlenbeck 式松弛。若 $c_0 \ge f_0$，则 $c(t) \ge f(t)$ 恒成立
（$(c-f)^{\cdot} = -\lambda (c-f) + \mu f \ge -\lambda(c-f)$）；若 $c_0 < f_0$，置信度不动、$c(t) < f(t)$，
一直到 $t_x$，此后 $c(t) \ge f(t)$。

**命题 3.1（精确半群）。** 设在 $[t_0, t_k]$ 内没有激活或否证（$n, d$ 与成熟度不变）。把区间任意
切分为 $t_0 < t_1 < \dots < t_k$ 并依次结算，得到的置信度与一次性结算**完全相同**。

*证明.* 方程右端 $F(t, c) = -\lambda (c - f(t))^{+}$ 关于 $c$ 是 $\lambda$-Lipschitz 的，初值问题的解存在唯一，
其流 $\varphi_{t_2,t_0} = \varphi_{t_2,t_1}\circ\varphi_{t_1,t_0}$ 是半群。严格地说这是增广自治系统
$(c, f)$（$\dot f = -\mu f$）的半群：从中间点 $t_1$ 重新起算时，地板用该点的值
$f(n, d, \tau + \Delta) = f(n, d, \tau)\,2^{-\Delta/\mathcal{E}}$ 重新计算，正是 $f_0 e^{-\mu(t_1 - t_0)}$，与整体解的地板
一致（$\Delta$ 的可加性用命题 2.1，即墙钟漂移不破坏它）。显式公式给出同一结论。$\square$

数值上，对 20 000 组随机 $(c, f, H, t_1, t_2)$（含 $c < f$ 与 $H \approx \mathcal{E}$）最大偏差为
$6\times10^{-13}$（`verify.py §3.2`）。此前的实现把地板冻结在区间终点，切分与否相差
$r_2(1 - r_1)(f_1 - f_2)$——$n=40$、切分 2000 + 3000 时为 0.0082，长间隔下可到 0.02
量级；这一"时代修正"正是成熟度轨迹依赖 reflect 频率时置信度残差的来源，现已消失。

**命题 3.1′（褪色边界是精确的）。** 置信度在事件之间单调不增（$\dot c \le 0$），因此在一个结算区间内
至多穿越 $\theta_{\text{fade}}$ 一次，穿越时刻 $t^{*}$ 取 $c(t) \ge \theta_{\text{fade}}$ 的最后时刻
（$c_0 = \theta_{\text{fade}} \le f_0$ 时置信度在平台上不动，取平台末端）。结算在 $[t_0, t^*]$
用成熟度对应的半衰期，在 $[t^*, t_1]$ 用 FADING 的半衰期，成熟度在 $t^*$ 记为 fading（`settle_concept`
用二分法求根）。结果与切分点无关：任何切分都落在穿越点的某一侧，各侧由命题 3.1 保证一致。

*证明.* 穿越前的相位是命题 3.1 的流，从任意中间点重新起算得到相同的 $t^*$（$t^* - t_m$）；穿越后同理。$\square$

此前，成熟度在 $\Delta$ 结束时才依据 $c < \theta_{\text{fade}}$ 改判，整个区间都用旧半衰期，而在区间中间
运行的 reflect 会让剩下的部分改用 FADING 的半衰期——同一个概念，结算是否发生在区间内部
决定了它剩下多少置信度（`verify.py §3.2` 与 `tests/test_maturity_schedule_maturity_b_monotone.py`）。
否证（`weaken`）与 `adjust_confidence` 也先结算再修改，并在事件上判定褪色边界，理由相同。

**定理 3.2（遗忘与 reflect 频率无关）。** 设一个概念在时刻 $a_1 < a_2 < \dots$ 被使用，
每次使用前先结算（`ConceptManager.reinforce`、`ActivationEngine` 的 `record` 路径都
这样做），此外 reflect 可以在任意时刻对它结算。若两种 reflect 安排下成熟度轨迹相同，
则每次使用之后、每次结算之后，两者的置信度**相等**；并且任意时刻两者的**结算值**
$\mathsf{Settle}_t(c)$（`settled_confidence`，不修改记录的读取）相等。存储的值在两次使用之间停在上次结算时；
激活与投影读取的是结算值（推论 3.2′），所以它们看到的也相等。

*证明.* 在每个使用间隔内，两种安排都是命题 3.1（及 3.1′）意义下的切分，且区间终点（下一次
使用之前）都做了结算，因此间隔终点处相等。使用时两者加上相同的增益 $b(n)$（只依赖计数），
截断 $\min(1,\cdot)$ 是同一个函数。按间隔归纳即得。$\square$

**推论 3.2′（读取与 reflect 无关）。** 在定理 3.7 的前提下，任意时刻的激活分数、投影的候选、选择、关系及其
顺序、语境拆分与"不再成立"列表都与 reflect 的安排无关。*证明.* 激活与投影只经由 `settled_confidence` 读概念置信度、
经由 `projected_relation_weight` 读关系权重，并把已死的边（结算权重 $< 0.02$ 或已撤回）与已死的概念
（`concept_expired`）当作不存在——这正是 reflect 的剪枝会做的，因此物理删除与否不改变读数；这些量都是结算后状态
的纯函数，由命题 3.1、4.2′ 与此前的结算切分无关。关系按结算权重排序。其余输入（证据、计数、显著性的时间项、
任务档案与词汇表）不受结算影响。渲染打印的 confidence 与成熟度标题是存储值，只是显示。$\square$ 实测：同一条流在同一 tick，reflect 过与未 reflect 的世界，种子分数都是 0.3165
（此前 0.317 对 0.489）。

没有"使用前结算"时这个定理不成立：激活把参照点移到"现在"，两次使用之间若没有
reflect，那段衰减就永远丢失了。这正是 §12 的缺陷 F4。F4 修复当时（成熟度仍只在 reflect 中评估，
地板冻结在区间终点）每 24 次观察使用一次、共 30 次后的置信度：

| reflect 频率 | 每 1 次 | 每 50 次 | 每 1000 次 | 从不 |
|---|---|---|---|---|
| F4 修复前 | 0.314 | 0.584 | 0.925 | 0.925 |
| F4 修复后 | 0.309 | 0.309 | 0.309 | 0.309 |
| F6 之后（精确半群 + 事件时晋升） | 0.758 | 0.758 | 0.758 | 0.758 |

（每 168 次使用一次：0.476 × 4；每 720 次：0.296 × 4，`verify.py §3.2`。）第三行数值高于第二行，
不是衰减变弱，而是成熟度轨迹改变了：概念在第 3 次使用时就是 developing、第 12 次起是 established，
半衰期随之变长；"F4 之后"一行里成熟度只在 reflect 时才变，所以那一行里一个从不 reflect 的概念在

### 3.3 噪声与遗忘

**命题 3.3（六次确认阈值）。** 无否证时，证据地板的时刻零值
$f(n, 0, 0) = \phi_{\max}\frac{n+1}{n+2}\big(\frac{n}{n+10}\big)^2$ 关于 $n$ 严格递增，且

$$
f(n, 0, 0) < \theta_{\text{fade}} \iff n \le 6 .
$$

*证明.* 三个因子都关于 $n$ 递增。直接计算：$f(6) = 0.35 \cdot \tfrac78 \cdot (\tfrac{6}{16})^2 = 0.0431$，
$f(7) = 0.35 \cdot \tfrac89 \cdot (\tfrac{7}{17})^2 = 0.0527$。$\square$

**推论 3.4（一次性提及的命运）。** 首次提及后 $c_1 = 0.2056$，$f \approx 0.0019$，
$H = 24$。闲置 $\tau$ 次观察后 $c = f + (c_1 - f)2^{-\tau/24}$，因此

- 在 $\tau_{\text{fade}} = 24 \log_2\frac{c_1 - f}{0.05 - f} = 50.0$ 次观察后标记为 fading；
- 在 $24 \log_2\frac{c_1 - f}{0.02 - f} = 83.9$ 次后低于剪枝阈值 0.02；
- 因剪枝宽限期（闲置 ≥ 720），在第 **720** 次观察被删除。

三个数值与引擎逐步模拟一致（`verify.py §3.3`）。反过来，被确认 $n \ge 7$ 次的概念
在不被否证时不会因闲置而进入 fading，直到时代项把地板降到阈值以下：
$\tau \ge \mathcal{E}\log_2\big(f(n,0,0)/\theta_{\text{fade}}\big)$（$n=30$ 时约 8 460 次观察）。

**命题 3.5（稀疏节律的复现路径）。** 设概念以固定节律 $T$ 被使用（每次落在不同的 24-tick 窗口，即
$T \ge 24$），无否证。记 $\Pi = 720$（剪枝宽限期 `PRUNE_MIN_IDLE_TICKS`）。

(i) 若 $24 \le T \le \Pi$，则它在第

$$
n^{*} = \min\{\,n \ge 10 : e(n, 0) \ge \tfrac12\,\} = 12
$$

次使用时成为 established，**与 $T$ 无关，也与 reflect 的安排无关**。

(ii) 若 $T > \Pi$，则它**从不**成为 established：两次使用之间概念已经 fading 并闲置超过 $\Pi$，是"已死"的
（定义 3.6），每次提及遇到的都是新建的 $n = 1$ 节点。

*证明.* (i) 复现计数每次使用加一（$T \ge 24$），$T \le 720 < \mathcal{E}/2$ 保证链不被打断（§3.5）。概念被再提及时
（判定于上一个 tick，§3.5）闲置 $T - 1 \le 719 < \Pi$，从不"已死"，所以节点一直存在，第 $n$ 次使用后 $\rho = n$。
间隔门（定义 3.5）要求 $\rho \ge 10$、$e(n,0) \ge 0.5$、$\beta(n,0) = \frac{n+1}{n+2} \ge 0.8$。
$e(11, 0) = \frac{12}{13}\cdot\frac{11}{21} = 0.484$，$e(12, 0) = \frac{13}{14}\cdot\frac{12}{22} = 0.506$，故 $n^* = 12$；
$\beta(12,0) = 0.929$。三个量都只依赖计数，与置信度、与 $T$ 无关。developing 阶段
（$\rho \ge 3$ 且 $e \ge 0.15$）在第 3 次使用时满足（$e(3,0) = 0.185$）。
(ii) 首次提及后 $c_1 = 0.2056$；由推论 3.4，83.9 个 tick 后 $c < 0.02$ 且已 fading。$T - 1 \ge 720$ 时上一个 tick
的闲置已达 $\Pi$，概念已死，提及新建一个 $n = 1$ 的节点，命题对此后每次使用重复。因为 $n$ 从不超过 1
（更一般地，$n \le 6$ 的概念的证据地板低于褪色阈值，命题 3.3），闲置 $\Pi$ 之后必然已死。$\square$

实测（`verify.py §3.3`，含 reflect 每 50 次与从不两种安排）：$T = 24, 72, 168, 720$ 都在第 12 次使用成为 established
（第 265、793、1 849、7 921 次观察），此前分别需要 13、15、27、**324** 次使用（$T = 720$ 时约 23 万次观察）；
$T = 721, 800, 2000$ 在两种安排下都从不成为 established。

**为什么门是证据而不是置信度。** 旧门（复现 ≥ 10 且 $c \ge 0.3$）回答"这个概念是否稳固"时读的是
一个会衰减的量：稀疏节律下两次使用之间置信度回落到地板 $f$ 附近，而每次使用只把它抬高一个增益 $b(n)$，
平衡点由 $f \le \phi_{\max}\cdot 2^{-T/\mathcal{E}}$ 与增益共同封顶；旧命题因此只能保证 $T < \mathcal{E}\log_2(\phi_{\max}/0.3) \approx 974$ 时可达，并且
$T = 720$ 需要 324 次使用——"是否真实"被"现在是否显著"回答了。新门里每一项都是一条关于
持久性的陈述：

- $\rho \ge 10$：在十个不同的 24-tick 窗口里被使用过——**间隔**证据，一次突发的三十次提及只算一次；
- $e(n,d) \ge 0.5$：与元认知层的 *well evidenced* 线（`WELL_EVIDENCED`）是同一条线，所以**间隔使用**（$\rho \ge 10$）
  的概念在被告知"证据充分"时已是 established，标为 established 的概念也正是被告知可以信赖的那些
  （突发提及的概念可以证据充分而仍是 developing，因为 $\rho$ 不够——突发对照见 §3.5 的表）；$e$ 与时间无关，
  $n^* = 12$ 恰是 $e$ 首次越过 0.5 的确认次数；
- $\beta(n,d) \ge 0.8$（后验均值）：确认至少是否证的约四倍，把有争议的概念挡在外面。

诚实的负面结论有两条。其一，$T > \Pi$ 的节律下概念在积累到 7 次确认之前就被当作噪声遗忘（命题 3.5(ii)）：这是
命题 3.3 与剪枝宽限期的直接推论，不是缺陷，但它意味着稀疏使用的好处只到 $\Pi = 720$ 为止。其二，对已经越过
噪声线（$n \ge 7$）的概念，闲置不会让它被剪枝，但复现链在 $\mathcal{E}/2 = 2190$ 个 tick 的间隔上断开（$\rho$ 回到 1），
它要重新赢得 established（§3.5 的链断规则）；旧的 974 界被这两条取代。

### 3.4 证据与显著性

**定义 3.4（证据与显著性，`ConceptNode.evidence`、`ConceptNode.salience`）。**

$$
e(n, d) = \frac{n+1}{n+d+2}\cdot\frac{n}{n+10}, \qquad
s(\tau) = \max\Big(\underbrace{\max\big(0.1,\ 2^{-\tau/168}\big)}_{\text{新鲜度}},\ \ 0.7\, e\, 2^{-\tau/\mathcal{E}}\Big).
$$

$e$ 与时间无关（"它是真的吗"），$s$ 与时间有关（"它现在在场吗"）。

**命题 3.6.** (i) $e$ 关于 $n$ 严格递增、关于 $d$ 严格递减，取值于 $[0,1)$；
(ii) $s \in [0.1, 1]$；(iii) 被确认 $n$ 次后闲置的概念，其显著性高于新鲜度下限 0.1 的
时间为 $\mathcal{E}\log_2(7e)$。$n = 50$ 时为 11 021 次观察，而一次性提及
（$e \approx 0.06$，$0.7e < 0.1$）从不高于下限。

*证明.* (i) 两个因子关于 $n$ 递增、第一个关于 $d$ 递减。(ii) 两项都在 $[0,1]$ 中，第一项
$\ge 0.1$。(iii) 解 $0.7 e\, 2^{-\tau/\mathcal{E}} = 0.1$。$\square$

### 3.5 成熟度：事件时评估的时间无关门

成熟度决定半衰期 $H_m$，所以"何时晋升"和"是否晋升"同样影响之后的衰减。旧实现在 reflect 里评估晋升，
读的是当时（已衰减的）置信度和当时的连接数，于是同一条观察流在不同 reflect 习惯下走出不同的成熟度
轨迹（第 3.2 节的表；§12 的 F6）。

**定义 3.5（晋升门，`dynamics/lifecycle.py`）。** 记 $n, d$ 为确认 / 否证次数，$\rho$ 为当前复现链的窗口数，
$e(n,d)$ 为定义 3.4 的证据，$\beta(n,d) = \frac{n+1}{n+d+2}$，$c$ 为置信度，$k$ 为存活连接数。满足任一门即晋升，
每次一直爬到不动点：

| 晋升 | 密集门 | 间隔门 |
|---|---|---|
| embryonic → developing | $n \ge 3 \wedge c \ge 0.3$ | $\rho \ge 3 \wedge e \ge 0.15$ |
| developing → established | $n \ge 10 \wedge \rho \ge 3 \wedge c \ge 0.6$ | $\rho \ge 10 \wedge e \ge 0.5 \wedge \beta \ge 0.8$ |
| established → core | $n \ge 30 \wedge k \ge \max\big(2,\ 5 - \lfloor (n-30)/20 \rfloor\big)$ | — |

$e \ge 0.15$ 与 $e \ge 0.5$ 就是元认知层的 `TENTATIVE_EVIDENCE` 与 `WELL_EVIDENCED`（测试固定二者相等）。
$\rho = 0$ 的记录（早于复现计数、或没有 tick 的记录）无法按间隔判定，密集门对它不要求 $\rho$。
**存活连接**数的是经由至少一条存活关系相连的不同邻居：一条关系存活，是指它结算后权重不低于剪枝线 0.02、未被撤回、
另一端的概念没有"已死"，而不是当前还在存储里；同一对概念上的几条主张（例如 "depends on" 与 "contains"）只算一个邻居。
reflect 是否已经把死边和死概念物理删除不影响计数（定义 3.6）。**复现链**：距上次激活不少于 $\mathcal{E}/2 = 2190$ 个 tick 的激活结束旧链、开启新链
（$\rho = 1$）；复苏落在哪一级仍按旧链判定（`REVIVAL_RECURRENCE`），随后链重新开始。
链的存在是为了让"淡出后被重新提起"的概念重新赢得 established：一个证据门（$n, d$）不会随时间失效，
而一个 $n \ge 10$ 的概念要因闲置而 fading，（无否证时）至少需要 $\mathcal{E}\log_2\big(f(10,0,0)/\theta_{\text{fade}}\big) \approx 2986$
个 tick，比链断的阈值 2190 长，所以每一次从时代尺度的褪色中复苏都开启新链。（有否证时更短：$n=10, d=3$ 约 1 576 个
tick 即 fading，此时链未断，复苏按 `REVIVAL_RECURRENCE` 落在 developing，并保留 $\rho$。）

**命题 3.7（门只在事件上变真）。** $n, d, \rho$ 只在激活 / 否证事件上变化，置信度只在激活事件上上升，存活连接
数只在关系被创建 / 强化的事件上上升；两个事件之间时间只让置信度与边权重下降。所以在事件之间，任何门的真值
只能从真变假或保持，**不会从假变真**。（密集门的置信度项与连接项在事件当刻取值——"这一次突发是否把
置信度推过了 0.6"是事件本身的性质；间隔门只含计数。）

因此评估放在事件上：每次激活之后（`ConceptManager.reinforce`）、每次关系创建 / 强化之后对两个端点
（`RelationManager`，先结算旧半衰期下欠下的衰减，再评估）。`LifecycleEngine.evaluate()`（reflect）只是对经由
其他途径变更的记录（合并、导入、手工编辑）的追赶；对经由 `ingest` 驱动的世界它不产生新的晋升，
只报告自上次 reflect 以来的晋升。

**定义 3.6（已死与惰性回收，`decay.concept_prunable`、`concept_expired`、`relation_dead`）。** 概念在结算后满足
fading $\wedge$ $c < 0.02$ $\wedge$ 闲置 $\ge \Pi$ 时**已死**；关系在结算后权重 $< 0.02$ 时已死。已死是结算后状态的
谓词，没有事件时单调（一旦成立就保持成立）。已死的对象在事件上被当作不存在：摄入时已死的概念先连同它的关系被
删除，再新建（`IngestPipeline._reap_if_expired`）；关系的重述与共现遇到已死的边时先删除再新建
（`RelationManager.reap_dead_between`）；物理删除（reflect 的剪枝）只是垃圾回收。判定取"reflect 最后可能运行的
那个 tick"，即当前观察的前一个 tick——恰好 720 的节律因此不被误伤。

**定理 3.7（存在性、成熟度与置信度与 reflect 频率无关）。** 固定一条观察流（每个概念的激活、否证、关系事件及其
时刻）。让 reflect 在任意时刻集合上运行（可以为空），最后再运行一次。则每个概念最终的（存在性、成熟度、置信度、
确认数）与 reflect 的安排无关；置信度只差墙钟漂移项（实测 $\le 3\times10^{-9}$）。**前提**：reflect 的另一项独立工作
——Hebbian 再验证（`revalidate`，只删除低关联的共现边）——删除的边，在删除时不是某个概念 core 门恰好依赖的
那一条（见下）。

*证明.* 对事件按时间归纳。归纳假设：事件之前，所有**存活**对象的状态（概念的 $n, d, \rho, c$、成熟度，关系的
$w, k, p$）与 reflect 安排无关。事件读取状态的方式只有四种，都不依赖已死对象是否还在存储里：(a) 结算，由命题 3.1、
3.1′、4.2′ 与切分无关；(b) 概念查找，先按定义 3.6 回收已死者；(c) 关系查找，先回收该概念对之间已死的边；
(d) core 门的存活连接数，按定义 3.6 只数存活边和存活邻居。每个事件的写入（激活的增益、否证、强化、确认、削弱）
都只依赖这些读数和流本身，因此事件之后的存活状态仍与安排无关；成熟度的四类改变时刻（激活、关系事件、否证、
结算内部的褪色穿越）分别由流、流、流和命题 3.1′ 决定；命题 3.7 保证 reflect 时的追赶评估不多晋升任何概念。
最后一次 reflect 之后，已死者都已删除，存活者的状态相同。$\square$

**前提与残余.** (1) **再验证。** reflect 独有的关系删除只有 Hebbian 再验证：它删除关联已低于截断线的共现边。共现边
的权重在最后一次强化后约 300 个 tick 内衰减到 0.02 以下，所以只有当一个概念的第 30 次确认恰好落在这个窗口里、且
它的 core 门恰好依赖这一条边时，从不 reflect 的世界才会与 reflect 过的世界不同。这个窗口在 340 条含关系与否证的
随机流（2 500 与 4 000 个 tick，reflect 每 1 / 50 / 1 000 次、轻量与完整）中没有被命中，但没有被证明不可能。
(2) **读取路径。** 激活读取结算值（推论 3.2′），所以事件之间的投影也与 reflect 无关；渲染里打印的"confidence"
是存储值，只是显示。
(3) **墙钟。** 认知时间里含一个很弱的墙钟项（每小时 0.1 tick），所以"相同"是指差不超过漂移量；两个概念的
置信度若恰好落在同一个门的两侧不到 $10^{-8}$，它们的判定在理论上可以不同。

## 4. 关系动力学

### 4.1 三种证据

关系有三个量，由三种证据分别驱动（`schemas/relation.py`）：

| 量 | 被什么改变 | 不被什么改变 |
|---|---|---|
| 操作权重 $w_e$、结构置信度 $k_e$ | 强化（显式重述或共现）、否证、时间 | — |
| 语义概率 $p_e$ | 显式确认、否证、抽取给出的概率 | **时间** |

强化：显式边 $w \leftarrow \min(1, w + 0.08/(1 + 0.05 r))$；共现边
$w \leftarrow \min(0.7, w + 0.06/(1 + 0.15 r))$。因此**共现边的权重永远不超过 0.7，
显式边可达 1**。显式边以其语义类型的传播强度为初始权重。初始概率（信念）对 positive /
parallel 同样取传播强度；对 negative 轴取 $p_0 = 0.70$（`NEGATIVE_CLAIM_PRIOR`，即一次
陈述的 `dependence` 所带的信念）——negative 轴的传播强度（0.05–0.12）是抑制通道的
增益，不是"该主张为真"的信念，二者是两个量：信念播种 $p_e$，增益播种 $w_e$。共现边以
0.15 起步。

**命题 4.1（确认的闭式，`RelationEdge.confirm`）。** 第 $k$ 次无附带概率的显式确认后

$$
p_k = 1 - (1 - p_0)\,0.95^{k}.
$$

*证明.* $1 - p_{k+1} = (1 - p_k)(1 - 0.05)$。$\square$

例：$p_0 = 0.70$ 经 20 次确认到 0.8925。

**命题 4.2（语义概率不随时间变化）。** 结算算子 $\mathsf{Settle}$ 不改变 $p_e$。

*证明.* `settle_relation` 只写 $w_e$、$k_e$ 与结算时刻。$\square$

这是一个设计选择而非推论："时间流逝不是反对一条关系的证据，只是反对它当前显著性
的证据"。

### 4.2 存续

**定义 4.1（关系结算，`decay.settle_relation`）。** 半衰期 $H^r = 72(1 + 0.5 r_e)$；
显式边的地板 $f^r = \eta\, p_e\, 2^{-\tau/\mathcal{E}}$（$\tau$ 为距最近强化的时间），共现边地板为 0。
$w$ 与 $k$ 与概念用同一个求解器向移动的地板松弛：区间起点的地板为 $f^r_0$，区间内 $f^r(t) = f^r_0 e^{-\mu (t-t_0)}$，
结算是 $\dot w = -\lambda^r (w - f^r(t))^{+}$ 的精确解（`relax_confidence`）。权重低于 0.02 的关系**已死**
（定义 3.6），reflect 时被剪枝，事件上被当作不存在。

**命题 4.2′（关系结算是精确半群）。** 在没有强化、确认、否证（$r_e, p_e$ 与最近强化时刻不变）的区间内，任意切分
依次结算与一次结算给出相同的 $w, k$。证明同命题 3.1。此前关系用"地板冻结在区间终点"的方案，切分的残差不超过
$\eta p_e(1 - 2^{-\Delta/\mathcal{E}})$，长间隔下可达 0.05，足以让一条临近剪枝线的边的存亡随结算频率变化
（一次陈述的显式边存续 8 070 / 8 100 / 8 200 / 9 000 次，取决于每 10 / 50 / 200 / 1 000 次结算——后两个是探测步长
的量化；现在死亡时刻与步长无关，`verify.py §4.2`）。所有修改关系状态的事件（强化、确认、削弱、带先验的重述、
`adjust_strength`）都先结算。

**命题 4.3（显式关系的存续下界）。** 若显式关系在最近一次强化后未被否证、且两端概念没有已死，则它
至少存续

$$
T_{\text{keep}} \;\ge\; \mathcal{E}\log_2(5\,p_e)
$$

次闲置观察才可能被剪枝。

*证明.* 创建时 $w_0$ 是传播强度：positive / parallel 边 $w_0 = p_0 \ge \eta p_0 = f^r(0)$；negative
边 $w_0 \ge 0.05 > 0.02$，可以低于 $f^r(0) = 0.07$（`disjointness` 0.05）。强化只增加 $w$；结算只把
$w$ 向 $f^r$ 拉近而不越过它，故 $w \ge \min(w_0,\ f^r(t))$（由 $f^r$ 单调不增，对切分归纳）。因此只要 $f^r = 0.1\,p_e\,2^{-\tau/\mathcal{E}} \ge 0.02$，就有 $w \ge 0.02$。解出 $\tau$
即得。$\square$

**注（信念的来源：负向主张）.** 下界对每个显式主张成立，但它是关于 $p_e$ 的，所以 $p_e$ 必须是
**信念**。修复前显式边的初始概率取传播强度，而 negative 轴的传播强度（`conflict` 0.10、
`disjointness` 0.05）是抑制通道的增益。于是一次陈述的 `conflict` 从 $p = 0.10$ 起步，地板
0.010 低于剪枝阈值 0.02、下界为负：概念保持活跃、关系不重述时，`conflict` 闲置 450 次、
`disjointness` 闲置 350 次后被剪，同样只陈述一次的 `depends_on` 是 8 100 次（分别是 18 倍与 23 倍）。现在
negative 轴的默认信念是 $p_0 = 0.70$：一次陈述的 `dependence`（本文的参照关系，也是 positive
轴上最弱的主张）所带的信念，因此一次陈述的主张在两条轴上地位相同。抑制增益（`weight`）不变，
激活的抑制通道也不变。实测（`verify.py §4.2`）：`depends_on`、`conflict`、`disjointness` 一次陈述
都是下界 7 916、实际 8 100；重述五次都是 8 501 / 9 250。信念低于 0.2 的主张（抽取器给出的
"多半不对"，或被否证到这一步的主张）地板仍低于阈值、仍不受保护——这是有意的，那是噪声。
修复前已存的 negative 显式边在加载时一次性重定基（`RelationEdge.adopt_claim_prior`）：若存储的
信念恰是"旧种子（增益）加上它自己的确认 / 否证计数"所能解释的，就以 0.70 为起点重放同样的
计数；否则那是抽取器或反馈给出的信念，原样保留。

**注（上界与滞后）.** 地板在移动，而 $w$ 以半衰期 $H^r$ 追随它，因此存在滞后：
连续结算时 $w - f^r \approx f^r H^r/\mathcal{E}$，存续时间趋于
$\mathcal{E}\log_2\big(5p_e(1 + H^r/\mathcal{E})\big)$。结算是精确的，所以滞后与结算频率无关。实测：
$p = 0.70$ 下界 7 916，实际 8 100；$p = 0.768$（五次重述）下界 8 501，实际 9 250（`verify.py §4.2`）。
下界的前提含"两端概念存活"：一个一次性伙伴在约 720 个 tick 后已死，它的边随它一起被回收，远早于 7 916
（`verify.py` 的存续检验把端点手工保持存活，只检验关系本身；概念侧见命题 3.5 与定理 3.7）。

### 4.3 对立主张

**定义 4.2（对立，`RelationEdge.opposes`）。** 两个主张对立，当且仅当二者都不是
`generic_relation`，且恰有一个在 negative 轴上。

**命题 4.4（对立是对称关系）。** 对任意语义关系 $\sigma_1, \sigma_2$，
$\sigma_1$ 与 $\sigma_2$ 对立 $\iff$ $\sigma_2$ 与 $\sigma_1$ 对立。

*证明.* 定义中的两个条件都关于交换对称。$\square$

这个显然的命题在修复前**不成立**（§12，F2）：代码只检查被削弱一方是否为
`generic_relation`，于是一句"A related_to B"会削弱已有的"A conflict B"，反过来则不会。
`verify.py §4.3` 对全部 $26^2 = 676$ 个有序语义对检验了对称性。

摄入一个显式主张时，同一概念对上与之对立的显式主张各被否证一次
（$p \leftarrow \max(0.01,\ p - 0.06/(1 + 0.1\delta))$）。因此两组对立陈述会相互竞争，
而不是双双保持高置信度；共现边与 `generic_relation` 不参与。

**注（对立主张的先验对称）.** 修复前一对对立主张的先验是 0.76（`enables`）对 0.10（`conflict`），
所以"`enables` ×10 再 `conflict` ×10 → 0.45 对 0.43"的势均力敌部分是先验不等的产物：交换
两条主张的角色（`conflict` ×10 再 `enables` ×10）得到 0.03 对 0.85。现在 `dependence` 与
所有 negative 主张都以 0.70 起步，交换轴得到**精确镜像**（`verify.py §4.3`，5 个序列）：
`dependence` ×10 再 `conflict` ×10 为 0.410 对 0.811，镜像为 0.811 对 0.410；交替均等重述
（EC ×10）为 0.498 对 0.528，`contested`；3 : 1 交替（EEEC ×5）为 0.682 对 0.358，`leaning`，
镜像同理。成块重述时**后一块领先**：确认是相对的 5% 步长，否证是绝对的
$0.06/(1+0.1\delta)$ 步长，一次对立陈述（首次 0.0545）抵得上约 3–4 次同向确认（0.70 处每次 0.015）。这个不对称对两条轴一样，本文
不改动该校准（§13）。

### 4.4 撤回

**定义 4.3（撤回，`Observation.retracted_relations`、`RelationEdge.retracted_tick`）。** "X 不再依赖 Y"是世界的一次修订，不是
主张曾经为假的证据。撤回把主张标为已撤回：信念 $p_e$ 不变；地板为 0（$w$ 松弛到 0 后按定义 3.6 已死）；不传播激活、不计入
core 门的连接、不进入投影的 `relations`，只在其端点是种子时列在 `Projection.retracted`（直到它已死）；共现既不强化它，
也不把这对概念当作已联结；显式重述使它恢复。合并两个概念时，合并后的主张只有在两边都已撤回时才是撤回的。

**命题 4.5.** 撤回不改变定理 3.7：已撤回的边在所有读取与门中都等同于不存在，撤回本身是流中的事件（先回收已死的边，
再在当刻判定）。*证明.* 撤回只写 `retracted_tick`；其后的读取都经由存活判定（推论 3.2′），与物理删除无关。$\square$
随机流中加入 25% 的撤回事件，14 个种子在 reflect 每 1 / 50 / 1 000 次与从不之下终态一致（概念、存活关系与撤回标记；置信度差 $\le 10^{-6}$，一例恰在六位小数的舍入边界上）。

## 5. 共现学习（Hebbian）

一对未联结的概念在同一观察中共现时，待定计数加一；当计数 $\ge 2$ **且**关联
$J \ge \theta_J = 0.2$ 时，创建一条 `generic_relation` 共现边。

**定义 5.1（关联，`HebbianEngine._association`）。**

$$
J(a,b) = \frac{C(a,b)}{n(a) + n(b) - C(a,b)},
$$

即提及 $a$ 或 $b$ 的观察中，同时提及二者的比例（观察集合上的 Jaccard 系数）。

**引理 5.1（Jaccard 是两个条件概率的函数）。** 令 $\hat P(b \mid a) = C/n(a)$，
$\hat P(a \mid b) = C/n(b)$，则

$$
J = \Big(\frac{1}{\hat P(b\mid a)} + \frac{1}{\hat P(a\mid b)} - 1\Big)^{-1}.
$$

*证明.* 分子分母同除以 $C$。$\square$

因此关联门是对两个方向条件概率的**联合**要求：任一方向很弱都会拉低 $J$，这正是
"枢纽概念不与偶然相遇者联结"的机制。

**推论 5.2（对称阈值）.** 若 $\hat P(b\mid a) = \hat P(a\mid b) = \rho$，则
$J = \rho/(2 - \rho)$，而

$$
J \ge \theta_J \iff \rho \ge \frac{2\theta_J}{1+\theta_J} = \frac13 .
$$

**命题 5.3（两种世界的渐近关联）。**

(i) *独立提及。* 若 $a$、$b$ 以概率 $q_a$、$q_b$ 独立出现在每次观察中，则几乎必然
$J \to \dfrac{q_a q_b}{q_a + q_b - q_a q_b}$；对称时为 $q/(2-q)$。

(ii) *话题结构。* 若每次观察从某个大小为 $m$ 的话题中无放回抽取 $k$ 个概念（话题
以概率 $\pi$ 被选中），则同话题的两个概念满足 $\rho = \frac{k-1}{m-1}$，
$J \to \rho/(2-\rho)$，**与话题频率 $\pi$ 无关**。

*证明.* (i) 由强大数定律，$C/N \to q_a q_b$、$n(\cdot)/N \to q_\cdot$，代入定义 5.1 并由
连续映射定理即得。(ii) $P(a \in o) = \pi k/m$，$P(a, b \in o) = \pi\frac{k(k-1)}{m(m-1)}$，
比值为 $\rho$，$\pi$ 被约去；再用推论 5.2。$\square$

数值：60 个概念每次随机取 6 个时 $q = 0.1$，$J_\infty = 0.0526$（模拟 0.035–0.055），
远低于门槛；6 个概念的话题每次取 4 个时 $\rho = 0.6$，$J_\infty = 0.4286$（模拟
0.41–0.44），远高于门槛。这解释了第八轮扫描中"随机蔓延 85 % → 9 %、同话题 100 %"
的结果，且说明它不依赖于话题出现的频率。

**关联门需要门槛计数的原因.** 早期统计很薄：两次提及、两次都在一起，$J = 1$。
因此 reflect 会用累积统计重新审查共现边（`HebbianEngine.revalidate`）：当两端的提及
合计 ≥ 20 且 $J < \theta_J/2 = 0.1$ 时移除。

**命题 5.4（滞回无振荡）。** 若提及统计平稳，使得 $J_t \to J_\infty$ 且
$J_\infty \notin \{0.1, 0.2\}$，则一对概念的联结状态最终不再改变。

*证明.* 若 $J_\infty > 0.2$：最终 $J_t > 0.2 > 0.1$，已联结的不会被移除，未联结的在下次
共现时被联结。若 $J_\infty < 0.1$：最终不会被创建，已有的在下次 reflect 被移除。若
$0.1 < J_\infty < 0.2$：最终既不满足创建条件也不满足移除条件，状态冻结在当时的值。
三种情况都只有有限次改变。$\square$

**关于计数的精确性（§12，F3）.** 命题 5.4 要求 revalidate 看到的是真实的 $C(a,b)$。
修复前它用"强化次数 + 2"估计，这只在边恰好在第 2 次共现时创建才准确；关联门推迟
了创建时，估计值偏低。实测中真实共现 8 次、估计 4 次，关联从 0.25 被低估到 0.11，
几乎落到移除线上。第十八轮之后引擎为已联结对保存了精确计数，现在 revalidate 取
二者的较大值（旧存储仍回退到估计值）。

## 6. 扩散激活

### 6.1 聚合：有界 noisy-OR

**定义 6.1（`activation._accumulate`）。** 设 $S > 0$ 为最强种子的分数。对
$a, b \ge 0$，令 $\bar a = \min(1, a/S)$，$\bar b = \min(1, b/S)$，

$$
a \oplus_S b = S\big(\bar a + \bar b - \bar a\bar b\big) = S\big(1 - (1-\bar a)(1-\bar b)\big).
$$

**命题 6.1.** 在 $[0, S]$ 上，$\oplus_S$ 是以 0 为单位元的 t-余模（概率和的缩放）：
交换、结合、单调；并且

$$
\max(a,b) \le a \oplus_S b \le S,\qquad 0 < a, b < S \Rightarrow a \oplus_S b > \max(a,b).
$$

对任意 $a, b \ge 0$（包括超过 $S$ 的单路贡献），结果仍 $\le S$。

*证明.* 归一化后是概率和 $x + y - xy = 1 - (1-x)(1-y)$，它的交换、结合、单调、以 0 为
单位元都是标准性质。$1-(1-x)(1-y) \ge 1-(1-x) = x$；当 $0 < x, y < 1$ 时不等号严格。
截断保证 $x, y \le 1$，故结果 $\le 1$，乘以 $S$ 即得。$\square$

这一命题有两个运行上的推论：从两个种子**汇聚**到的概念严格高于只从一个种子到达
的概念（第一轮缺陷 C 修复的正是这一点）；聚合结果与路径到达的顺序无关（结合律）。

### 6.2 传播与秩保持地板

一条从已激活概念 $u$（分数 $a_u$，位于第 $j$ 层）到邻居 $v$ 的非负边贡献

$$
x_{uv} = a_u \cdot \underbrace{w_e\, \omega_P(e)\, \omega_{\text{dir}}(e)}_{\text{边强度}} \cdot \underbrace{\max(c_v, e_v, 0.3)}_{\text{就绪度}} \cdot \delta^{\,j+1} \cdot \gamma_{\text{task}}\, \gamma_{\text{dom}} \cdot \underbrace{\max\!\big(0.15, 2^{-\tau_e/(72(1+0.5r_e))}\big)}_{\text{关系新鲜度}} \cdot s_v ,
$$

其中 $\omega_P$ 是视角对该语义关系 / 轴的权重，$\omega_{\text{dir}}$ 只作用于有向边，
$\gamma_{\text{task}} \in [1, 1.5]$、$\gamma_{\text{dom}} \in \{1, 1.3\}$，$\delta$ 是深度衰减（`World.project`
默认 0.5）。negative 轴的边不写入任何层：同一乘积 $x_{uv}$ 经地板 $\varphi$ 后进入**可见性**通道（$v$ 作为$u$ 所陈述对比的另一端被看见），乘以 0.6 后进入独立的**抑制**通道（§6.3 命题 6.6）。

**定义 6.2（秩保持地板，`ActivationEngine._apply_floor`）。** 令 $F = 0.03\,S$，

$$
\varphi(x) = \begin{cases} x, & x \ge F,\\ F\,(0.9 + 0.1\,x/F), & 0 < x < F. \end{cases}
$$

**命题 6.2.** $\varphi$ 在 $(0, \infty)$ 上连续且严格递增，把 $(0, F)$ 映到 $(0.9F, F)$。

*证明.* 两段都是正斜率的仿射函数（斜率 0.1 与 1），在 $x = F$ 处两段取值都是 $F$。$\square$

这是对第一轮缺陷 D（常数地板把深层节点压成同分）的形式化：弱信号被抬升进一条
窄带，但彼此的顺序保留。

### 6.3 主要性质

**定理 6.3（种子支配）。** 设 $S$ 为种子分数的最大值（种子分数取结算值与任务提升之积，推论 3.2′）。对任何非种子概念 $v$，
其净激活 $a(v) - i(v) \le S$。每个种子都出现在激活结果中，分数为
$\max(0,\ s - i(s))$。

*证明.* 非种子概念的激活只能由某一层的 $\oplus_S$ 累加写入（命题 6.1：$\le S$），抑制非负，
故净值 $\le S$。种子的深度为 0，而兴奋只流向深度更大的层，所以种子的激活值从不
被覆盖。结果中保留种子是 §12 F1 修复后的行为。$\square$

**定理 6.4（视界完备性）。** 设种子 $u$ 的分数 $s_u \ge \text{cut} = \min(0.01, 0.02S)$。
若概念 $v$ 与 $u$ 之间存在一条长度 $\le D$ 的路径，路径上每条边都是非负轴、**存活**（未撤回，结算后权重
$\ge 0.02$）、视角权重为正，路径上的概念都未死（定义 3.6），则 $v$ 的兴奋激活 $\ge 0.027\,S$。因此 $v$ 出现在结果中，除非它被抑制到
cut 以下（而且没有任何陈述的对比使它可见，命题 6.6）。

*证明.* 对层数归纳，证明路径上第 $j$ 个概念要么已在更浅的层被激活，要么在第 $j$ 层
获得 $\ge 0.027S$ 的兴奋。第 $j$ 层的源分数 $\ge 0.027S > 0.02S \ge \text{cut}$，因此会被展开；
贡献 $x > 0$，因为每个因子都为正（就绪度 $\ge 0.3$，关系新鲜度 $\ge 0.15$，显著性 $\ge 0.1$）。
由命题 6.2，$\varphi(x) \ge \min(x, 0.9F)$；而当 $x < F$ 时 $\varphi(x) \ge 0.9F = 0.027S$，
当 $x \ge F$ 时 $\varphi(x) = x \ge F$。两种情况都 $> \text{cut}$，因此被写入该层，又由命题 6.1
$\oplus_S$ 不减少。$\square$

这给出了"地板把认知视界从 1 跳扩展到 3–4 跳"的精确版本：**在给定深度内，视界
是完整的**，任何经存活的非负边可达的概念都不会因乘积链变小而丢失；已死的边与概念不论 reflect 是否已物理删除，
都不参与传播（推论 3.2′）。视界的边界由 $D$ 和
视角权重（权重为 0 即切断）决定，而不是由乘积的数值下溢决定。

**命题 6.6（陈述的对比使另一端可见，但不是路径）。** 设种子 $u$ 的分数 $s_u \ge \text{cut}$，
$e$ 是 $u$ 与 $v$ 之间一条存活的 negative 轴边，视角权重为正，$v$ 未死。记 $x_{uv}$ 为 §6.2 的乘积
（取 $\omega_P$ 为 negative 轴的权重）。则

1. **可见**：$v$ 出现在结果中，净分 $a^\ast(v) \ge \varphi(x_{uv}) \ge 0.027\,S$；一般地，
   对任何概念 $v$，$a^\ast(v) = \max\big(\mathrm{vis}(v),\ a(v) - i(v)\big)$，其中 $\mathrm{vis}(v)$ 是各层
   negative 边贡献 $\varphi(x)$ 的 $\oplus_S$ 累加，$i(v)$ 是同一批贡献乘以 0.6 的 $\oplus_S$ 累加。
2. **终端**：若 $v$ 只经 negative 边到达（没有任何非负边路径使它进入某一层），则 $v$ 不被展开；
   仅经 $v$ 可达的概念不被激活。
3. **排序**：在其余因子相同的条件下（同一源、同样的边权、就绪度、新鲜度与深度），$u$ 经一条
   positive 轴边到达的邻居 $v^+$ 的激活不低于经 negative 轴边看见的邻居 $v^-$：
   $\varphi(x_{uv^+}) \ge \varphi(x_{uv^-})$，因为 $\omega_P(\text{positive}) = 1.0 \ge 0.6 = \omega_P(\text{negative})$
   且 $\varphi$ 单调。
4. 定理 6.3 的上界不变：$\mathrm{vis}(v) \le S$，故 $a^\ast(v) \le S$。

*证明.* (1) $u$ 在第 0 层被展开（$s_u \ge \text{cut}$）。negative 分支把 $\varphi(x_{uv})$ 写入可见性通道，
$x_{uv} > 0$ 的理由与定理 6.4 相同，于是由命题 6.2 $\varphi(x_{uv}) \ge \min(x_{uv}, 0.9F) \ge 0.027S > \text{cut}$；
最终 $a^\ast(v) = \max(\mathrm{vis}(v), \cdot) \ge \mathrm{vis}(v) \ge \varphi(x_{uv})$（命题 6.1：$\oplus_S$ 不减少）。
(2) 只有写入层的概念才进入下一层的前沿；negative 分支以 `continue` 结束，不写入层。(3) 两个乘积只在
$\omega_P$ 上不同。(4) 由命题 6.1。$\square$

这是对"$A$ 与 $B$ 冲突"这一**关于二元组的知识**的刻画：知道 $A$ 就知道它与 $B$ 对立，所以 $B$ 以对比
的强度出现在 $A$ 的视图里；但 $B$ 的邻域不因此被拉进来——对立不是通往 $B$ 那一侧世界的路径。
抑制仍然作用于 $B$ 经其他路径得到的兴奋：$a^\ast(B)$ 以 $\mathrm{vis}(B)$ 为下界，以兴奋减抑制为上界之外的
另一路；LongRun 上这把 focus 查询里 conflict 主张的召回从 0.84 提到 0.99（分析文档 §7.30）。
`verify.py §6.3` 检验 (1)–(3)。

**命题 6.5（终止性与代价）。** 激活至多执行 $D$ 层；每个概念至多被赋予一次深度、
至多展开一次；每条关系至多从两端各扫描一次。设被触及的子图为 $(V_D, E_D)$，
单次激活的代价为 $O\big((|V_D| + |E_D|)\cdot \bar\pi\big)$，$\bar\pi \le 64$ 是任务画像的大小。

*证明.* 一个概念被写入第 $j+1$ 层后深度为 $j+1$；此后在第 $j' \ge j+1$ 层处理时，条件
"深度 $\le j'$"使它被跳过，故它只进入一次前沿。每个前沿成员只扫描自己的邻接表一次，
因此每条边至多扫描两次。每条边上的主要附加开销是任务亲和度查询，代价与画像大小
成正比。$\square$

## 7. 投影

### 7.1 相关性

对候选 $v$（激活不低于 cut，或者是种子），投影计算

$$
\mathrm{rel}(v) = \frac{a(v)}{a_{\max}} \cdot \underbrace{\big(0.6 + 0.4\,\alpha_v\big)}_{\tau_v} \cdot \underbrace{\big(0.7 + 0.3\,s_v\big)}_{\phi_v} \cdot \big(1 + \gamma\, \psi_v\big),
$$

其中 $\alpha_v = \max(\text{历史亲和},\ \text{词面锚定})$ 是任务亲和度，$s_v$ 是显著性，
$\psi_v \in [0, 1]$ 是焦点亲和度（未开启持续注意时为 0）。选择时先放入种子，再以

$$
\operatorname{mmr}(v) = (1 - \lambda)\,\mathrm{rel}(v) - \lambda\,\mathrm{red}(v),
\qquad \mathrm{red}(v) = \begin{cases} \max\big(\mathrm{sim}(v),\ 1 - \alpha_v\big), & 1-\alpha_v > \mu, \\ \mathrm{sim}(v), & \text{否则}, \end{cases}
$$

（已选集合为空时 $\mathrm{red} \equiv 0$，第一个位置只按相关性选取。）

贪心填充其余位置。这里 $\mathrm{sim}(v)$ 是 $v$ 与已选概念之间邻居集合 Jaccard 相似度的最大值，
$\mu$ 是剩余候选中最小的任务失配度。贪心只在地板带**之上**的候选（$a(v) \ge F = 0.03\,S$）中进行：
带内候选的分数是定义 6.2 为视界完备抬进来的，不携带可交换的证据强度，所以它们在带上候选用尽后
按激活降序补足剩余位置（分析文档 §7.31）。带内且已知语境是另一任务的候选是填充物，永不选入（§7.29）。

**命题 7.1（种子优先）。** 设 $\Sigma$ 为能解析到的种子集合，则投影包含 $\Sigma$ 中按分数
排列的前 $\min(|\Sigma|, K)$ 个。

*证明.* 由定理 6.3，每个种子都在激活结果中；投影的候选过滤对种子豁免；选择在 MMR
之前先放入种子。$\square$

修复前这个命题只对"激活后仍高于 cut 的种子"成立（§12 F1）：一个已褪色的种子
（置信度 0.004，另一个种子 0.9）在激活的净值截断中被丢弃，投影的豁免根本看不到它。

**命题 7.2（有界性）。** $\tau_v \in [0.6, 1]$，$\phi_v \in [0.73, 1]$，焦点乘子 $\in [1, 1.5]$，
$\mathrm{red} \in [0,1]$。特别地，任务亲和度至多使相关性相差 $1/0.6$ 倍，焦点至多使其
放大 1.5 倍。

**命题 7.3（离题候选等价于完全冗余）。** 若剩余候选中存在更贴合任务的（$1 - \alpha_v > \mu$），
则 $\mathrm{red}(v) \ge 1 - \alpha_v$；特别地，与任务毫无关联的候选（$\alpha_v = 0$）满足
$\mathrm{red}(v) = 1$，与一个邻居集合完全重合的重复项无法区分。离题候选 $x$ 胜过最贴合的
候选 $y$，当且仅当

$$
(1-\lambda)\big(\mathrm{rel}(x) - \mathrm{rel}(y)\big) > \lambda\big(\mathrm{red}(x) - \mathrm{red}(y)\big).
$$

*证明.* 由 $\mathrm{red}$ 的定义直接得出；最后一式是 $\operatorname{mmr}(x) > \operatorname{mmr}(y)$ 的改写。$\square$

这形式化了第九轮的修复：修复前"多样性"项会奖励一个仅与种子相邻、因此看起来
"不冗余"的离题概念，让它挤掉同话题的概念；现在离题本身就算作冗余，只有当它的
相关性优势大到足以抵消这一差距时才能入选。

**命题 7.4（无任务时退化为经典 MMR）。** 任务为空时 $\tau_v \equiv 1$、$\mu = 0$、失配度
$\equiv 0$，锚定为空，选择规则退化为以 $\frac{a}{a_{\max}}\phi(1+\gamma\psi)$ 为相关性、以邻居
Jaccard 为冗余的 MMR。

### 7.2 词面锚定

**定义 7.1（`context/grounding.py`）。** 设任务的词集为 $T$，概念名（或别名）的词集为
$N$，覆盖度为 $\kappa = |N \cap T|/|N|$（对没有签名词的名称，退化为整串包含：包含得 1，
否则得 0）。锚定亲和度 $g(v)$ 的定义是：若 $\kappa_v \ge 0.5$，则 $g(v) = \kappa_v$；否则，若 $v$ 与某个 $\kappa = 1$ 的
锚点相邻，则 $g(v) = 0.5$；否则 $g(v) = 0$。

**命题 7.5.** (i) $g \in \{0\} \cup [0.5, 1]$；(ii) 若任务没有覆盖任何候选名称的一半以上，
则 $g \equiv 0$，投影与只用历史亲和时完全相同；(iii) 单调性：若 $T \subseteq T'$，则
逐点有 $g_T \le g_{T'}$。再加上 $\alpha = \max(\text{历史}, g)$，**词面锚定永远不会降低任何
候选的任务亲和度**。

*证明.* (i)、(ii) 由定义直接得出。(iii) 覆盖度关于 $T$ 单调，因此在 $T$ 下的锚点在 $T'$
下仍是锚点，直接覆盖的值也不减。$\square$

### 7.3 任务词的区分度与语境

**定义 7.2（历史亲和，`task_match_score`、`TaskVocabulary`）。** 设世界里概念档案携带的不同任务标签共 $L$ 个，词 $t$
出现在其中 $d_t$ 个里，权重 $w_t = \ln\frac{L+1}{d_t+1} + \epsilon$，$\epsilon = 0.01$。查询任务的词集为 $Q$，某个历史标签的词集为 $B$：

$$
m(Q, B) = \frac{\sum_{t \in Q \cap B} w_t}{\sum_{t \in Q} w_t}
$$

（标签完全相同时为 1）。概念的历史亲和是它档案中各标签的
$m$ 的最大值；关系的历史亲和同理取其 `task_history`。

**命题 7.7.** (i) 每个标签都含有的词权重只有 $\epsilon = 0.01$（`TASK_WORD_FLOOR`），所以查询里只要有一个区分性的词，
共同的套话（"work"、"fix"、"bug"）就几乎不贡献匹配；只由套话组成的查询仍按套话匹配（权重都为正，分数随查询连续）；
(ii) 不加权的匹配是 $w \equiv 1$ 的特例；(iii) 词汇表是概念档案的函数（增量维护与从档案重建一致，重启后相同）。

*证明.* (i) $d_t = L$ 时 $w_t = \epsilon$；(ii) 显然；(iii) `ConceptManager` 在强化与删除时按档案键的差集增减计数，在合并、
拆分、记录路径的激活之后标记为需重建，加载时由档案重建。$\square$

LongRun 的全部任务都是"〈领域〉 work"，旧匹配给每个概念对每个任务至少 0.5 的亲和，任务标签在那里没有可测的作用。

**定义 7.3（语境拆分，投影 `CONTEXT_MATCH = 0.5`）。** 一条显式主张的语境是它被**陈述**时的任务
（`RelationEdge.claim_tasks`；共现带来的 provenance 不算）。给定任务时，主张*在语境内*当且仅当 `claim_tasks` 非空且
其亲和 $\ge 0.5$；*在语境外*当且仅当 `claim_tasks` 非空且亲和 $< 0.5$；从未在任务下陈述过的主张与共现边是中性的。
若视图中的概念 $v$ 至少有一条**存活**（未撤回、未死）的在语境内主张（在全图中），则连到 $v$ 的语境外主张从 `relations`
移到 `other_contexts`。元认知的争议判定在两者的并上进行，所以被移走的对立主张仍让一对主张显示为有争议。

**命题 7.8.** (i) 没有任务、没有任何关系在语境内、或概念从未在当前语境中出现过时，没有关系被移走；(ii) 被移走的关系
只是换了位置，渲染里在"Seen in Other Tasks"下列出；(iii) 概念的选择不受影响。

*证明.* 由定义直接得出。$\square$

这是对一词多义的最小处理：一个概念在当前任务里有自己的主张时，它在别的任务里的主张被视为另一个语境下的它；
一个概念在当前任务里没有主张时，没有证据说明它的主张属于别处，全部保留。代价是任务标签错误时会显示错误语境的主张
（LongRun 的"错标签"研究量化了这一点）。

**命题 7.6（确定性）。** 给定存储状态、时钟 tick 与墙钟时刻，投影是确定的函数：
候选按（相对最强激活量化到 $10^{-6}$ 的分数降序，最近激活者优先，名称，id）的顺序访问，关系按（权重降序，id）排序。
不依赖 `PYTHONHASHSEED` 或文件加载顺序。

## 8. 持续焦点（全局工作空间）

**定义 8.1（`context/focus.py`）。** 焦点是一个映射 $\mathcal{F}$：概念 → 强度 $\in (0,1]$。
每次投影后按下面的更新 $U$ 演化：

$$
\mathcal{F} \leftarrow \operatorname{top}_7\Big(\{v \mapsto 0.6\,\mathcal{F}(v) : 0.6\,\mathcal{F}(v) \ge 0.15\} \ \cup\ \{v \mapsto 1 : v \in \text{Ign}\}\Big),
$$

其中点燃集 $\text{Ign}$ 由两部分组成：全部种子，以及相关性不低于本视图最强非种子相关性一半的
已选概念。焦点亲和度对候选 $v$ 的定义是：

$$
\psi_v = \max\Big(\mathcal{F}(v),\ \max_{u \in N(v)\setminus \Sigma} 0.5\,\mathcal{F}(u)\Big)
$$

这里本次投影的种子 $\Sigma$ 不向邻居传递亲和。显式任务改变时焦点被清空。

**命题 8.1（容量与寿命）。** (i) $|\mathcal{F}| \le 7$ 恒成立。(ii) 一个只被点燃一次的
概念，如果没有被容量挤出，恰好在其后 $L = \lfloor \ln 0.15/\ln 0.6 \rfloor = 3$ 次更新中保留
（强度依次为 0.6、0.36、0.216），在第 4 次更新时离开（0.1296 < 0.15）。

*证明.* (i) 由 $\operatorname{top}_7$ 得出。(ii) 第 $j$ 次更新后强度为 $0.6^j$，保留当且仅当
$0.6^j \ge 0.15$。$\square$

**命题 8.2（只偏置，不注入）。** 对任意焦点状态，投影选出的概念集合是同一个候选集合的
子集，而这个候选集合与焦点无关（由激活决定）。

*证明.* 焦点亲和度只对候选计算，并且只进入相关性的乘子；候选的定义不含 $\mathcal{F}$。$\square$

**命题 8.3（有界偏置与无固着）。** 焦点使候选的相关性至多放大 1.5 倍；种子不传递
亲和；若新一轮的种子与焦点内容不相邻，则 $\psi \equiv 0$，投影与没有焦点时完全相同。

命题 8.1–8.3 共同说明：焦点是一个**有界、易逝、非注入**的注意状态，而不是记忆。
它无法让 Agent "看见"本轮激活没有触及的概念，也无法无限期地保留一个话题。

## 9. 预测误差

**定义 9.1（`HebbianEngine.prediction_error`）。** 在学习本次观察之前，对观察中每个被
提及 $\ge 5$ 次的概念 $a$、它的每个已联结伙伴 $b$，令 $p = C(a,b)/n(a)$；$p \ge 0.5$ 时记为
一条预测。设全部预测为 $\{p_j\}$，$X = \sum_{j:\,b_j \notin o} p_j$ 为缺席的预测质量，

$$
M = \sum_j p_j,\qquad V = \sum_j p_j(1-p_j),\qquad
\varepsilon_{\text{miss}} = \operatorname{clip}_{[0,1]}\frac{X - V}{M - V} = \operatorname{clip}_{[0,1]}\frac{X - V}{\sum_j p_j^2}.
$$

对观察中每一对支持度都 $\ge 5$ 但从未共现的概念，令 $\lambda_{ab} = n(a)n(b)/N$，
新组合度 $\varepsilon_{\text{nov}}$ 为 $1 - e^{-\lambda_{ab}}$ 在全部"已知对"上的平均。最终的意外度为
$\varepsilon = \max(\varepsilon_{\text{miss}}, \varepsilon_{\text{nov}})$。

**命题 9.1（取值与极值）。** $\varepsilon_{\text{miss}} = 1 \iff X = M$（全部预测缺席）；
$\varepsilon_{\text{miss}} = 0 \iff X \le V$。

*证明.* $X \le M$，且 $M - V = \sum p^2 > 0$。$\square$

**定理 9.2（在模型自身假设下的标定）。** 设在给定预测者出现的条件下，每个伙伴
$b_j$ 以其预测概率 $p_j$ 独立出现。则

$$
\mathbb{E}[X] = V, \qquad
\mathbb{E}[\varepsilon_{\text{miss}}] \;\le\; \frac{1}{2}\,\frac{\sqrt{\sum_j p_j^3(1-p_j)}}{\sum_j p_j^2}.
$$

*证明.* $X = \sum_j p_j \mathbb{1}[b_j \notin o]$，$\mathbb{E}\,\mathbb{1}[b_j\notin o] = 1-p_j$，得
$\mathbb{E}X = V$；同理 $\operatorname{Var}X = \sum_j p_j^2\,p_j(1-p_j)$。令 $Z = X - V$，则 $\mathbb{E}Z = 0$，
于是 $\mathbb{E}\max(0,Z) = \tfrac12\mathbb{E}|Z| \le \tfrac12\sqrt{\operatorname{Var}Z}$（Jensen）。
由于 $\varepsilon_{\text{miss}} \le \max(0, Z)/\sum p^2$，结论成立。$\square$

这个定理说明了第十八轮的标定为什么有效：原始的"缺席比例"把模型自己预期的波动
也记为误差，而减去 $V$ 之后，分子在模型正确时是**无偏**的，误差只剩下与预测数量
相关、可以界定的噪声。例：4 个 $p = 0.6$ 的伙伴时上界为 0.204，蒙特卡罗值为 0.173；
10 个 $p = 0.7$ 时上界为 0.104，实测为 0.081（`verify.py §9`）。上界随预测数 $n$ 按
$\tfrac12\sqrt{(1-p)/(np)}$ 衰减：伙伴越多，误差信号越干净。

**命题 9.3（新组合权重的含义）。** 在独立提及、提及率分别为 $q_a = n(a)/N$、$q_b = n(b)/N$
的零假设下，$N$ 次观察中两者从未共现的概率为 $(1 - q_a q_b)^N \le e^{-\lambda_{ab}}$。
因此，权重 $1 - e^{-\lambda_{ab}}$ 是"它们本应已经相遇"这一概率的**下界**，换言之是
"从未相遇"这一事件 p 值上界的补。

*证明.* $\ln(1-x) \le -x$。$\square$

例：各占一半历史（$n = 50$，$N = 100$）却从未相遇，权重为 1.000；两个都很少出现的概念
（$n = 5$，$N = 1000$），权重仅为 0.025。

**估计量.** $p = C(a,b)/n(a)$ 是 $P(b\mid a)$ 的最大似然估计；$C(a,b)$ 是自追踪开始以来的
精确共现数（待定计数在联结时迁入）。独立性假设是理想化：同一对概念会被双向预测
两次（$a \to b$ 与 $b \to a$），多个伙伴之间也可能相关。定理 9.2 的上界在这些情况下
不再严格，但分子的无偏性只依赖每条预测自身的边际概率，仍然成立。

## 10. 元认知

**命题 10.1（可靠性分级的计数刻画）。** 无否证时（$d = 0$），

$$
e(n) < 0.15 \iff n \le 2, \qquad e(n) \ge 0.5 \iff n \ge 12 ,
$$

即"暂定"（tentative）恰为被提及至多 2 次的概念，"证据充分"（well-evidenced）恰为

*证明.* $e$ 关于 $n$ 严格递增（命题 3.6）；$e(2) = 0.125$，$e(3) = 0.185$，$e(11) = 0.484$，
$e(12) = 0.506$。$e$ 不含时间变量。$\square$

contested，否则标为 leaning。由命题 4.4，报告与主张陈述的先后顺序无关。

| 操作 | 代价 | 说明 |
|---|---|---|
| 摄入 | $O(k \cdot \ell + \min(k^2, 30) + \sum_{a \in o}\deg(a))$ | $\ell$：身份解析的候选名单长度（第三轮索引）；共现对上限 30；预测遍历被观察概念的邻居；core 门对 $n \ge 30$ 的 established 概念的关系事件数一次该概念的邻居（$O(\deg)$，仅限中枢） |
| 结算（单个） | $O(1)$ | 使用前的惰性结算不改变摄入的渐近代价；褪色穿越的二分为常数步（60） |
| 激活 | $O((|V_D| + |E_D|)\,\bar\pi)$ | 命题 6.5 |
| 投影 | $O(C\,\deg + K\cdot C\cdot K\cdot \deg)$ | 邻居集合与 MMR 的逐对 Jaccard；$C$ 受激活截断约束 |
| reflect（轻） | $O(|V| + |E|)$ | 全体结算、生命周期、剪枝、revalidate |

实测（第十二、十八轮）：2 000 个概念时每次观察约 1.6 ms，投影约 0.4 ms。

## 13. 局限与未证明的部分

- **常数没有被推导。** 半衰期、阈值、增益都是标定出来的；本文只推导它们的推论。
  晋升门里的 0.5 与 0.15 借自元认知层，0.8 的平衡门与 2190 的链断阈值是本文选定的（见 §3.5 的取舍与
  实测）；稀疏节律 $T \ge \mathcal{E}/2$ 下 established 仍不可达，这是一个设计选择。
- **成熟度的调度依赖：只剩一个前提。** 定理 3.7 覆盖事件之后的状态，前提是 Hebbian 再验证不删除 core 门恰好依赖的共现边
  （§3.5 的残余 (1)）。此前列在这里的"已可剪枝的概念被再提及"已由惰性回收消除（F7）；"读取路径读的是存储值"已由
  读取时结算消除（推论 3.2′）。渲染打印的 confidence 仍是存储值（只影响显示）。
- **事件内的顺序。** 晋升在激活之后立即评估，同一次观察里紧随其后的否证尚未计入；这对所有 reflect 安排都一样，
  所以不破坏定理，但它意味着平衡门实际读到的比值比事件结束时略宽。
- **独立性假设。** 命题 5.3、定理 9.2、命题 9.3 都依赖独立或平稳假设。真实的观察流
  既不独立也不平稳（这正是概念漂移）。它们说明的是"在零假设下系统不会误报"，而
  不是"在真实数据上的精确误报率"。
- **MMR 没有近似保证。** 贪心 MMR 在一般情况下没有子模性保证；任务冗余项
  $\max(\mathrm{sim}, 1 - \alpha)$ 还会破坏目标函数的某些结构。本文只证明了它的局部性质
  （命题 7.3、7.4），没有证明全局最优性。
- **未覆盖的子系统。** 社群检测与色场动力学（`dynamics/community.py`、
  `dynamics/color_diffusion.py`）不在本文范围内；它们只影响 reflect 的重型步骤与
  领域亲和度，不影响本文的任何命题。
- **否证的步长与确认不对称，且不区分轴。** `confirm()` 是相对的（每次消除 5% 的剩余疑虑），
  `weaken()` 是绝对的（$0.06/(1+0.1\delta)$），所以成块重述时后一块领先，一次对立陈述抵得上
  约 3–4 次确认（见 §4.3 的注）。`weaken()` 还从**操作权重**里减去同一个绝对量：negative 轴的
  权重是抑制增益，量级 0.05–0.2，几次否证就压到 0.01 并被剪枝。实测（端点不共现，
  `contradicted_relations` 连续 6 次）：`conflict` 信念 0.43 时权重已是 0.010，下一次 reflect 即被剪；
  同样处境的 `depends_on` 权重 0.505，还能再存续 4 950 次观察。共现强化通常抵消这一点
  （两个概念同时出现使权重 +0.07），所以它只出现在没有共现的纯否证序列里。一种修法是让
  地板真的成为下限（结算时把权重抬到地板），但那会改变正向边被否证后的剪枝行为，本文不处理。
- **墙钟漂移。** 新鲜度含墙钟项（每小时 0.1 tick），因此投影在两次调用之间可以因为
  真实时间流逝而发生微小变化。命题 7.6 的确定性是以墙钟时刻为参数的。
