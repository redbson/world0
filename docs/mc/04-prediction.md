# 04 · 第十八轮：预测误差（PP-1）

## 1. 指标

PP-1：*input modules using predictive coding*。预测加工理论认为，感知是自上而下的预测
与自下而上的误差之间的交换；误差驱动学习与注意。落到 World 0：已经学到的共现就是关于
"什么会一起出现"的预测，每个新观察都可以先与之对照，再被学习。

## 2. 基线

`IngestResult` 只有增删改列表（新概念、强化、削弱、新关系、Hebbian 关系），没有任何
"这次观察有多出乎意料"的信号。一个观察完全重复旧模式，还是颠覆了旧模式，在接口上
看不出区别。此外，Hebbian 引擎在一对概念被联结后会丢弃其共现计数，之后只剩边的强化
次数；而强化次数里混有显式重述，不能当作共现数用。

## 3. 设计

**统计**：`HebbianEngine` 为**已联结**的概念对单独保留共现计数 `_linked`。联结时由待定计数
迁入，之后每次共现 +1；它随学习状态持久化（`learning.json` / SQLite 的 `learning` 行），
规模以关系数为上限。`revalidate()` 删除一条共现边时，计数回到待定表；`forget_concept()`
清除相关计数。

**预测**：概念 `a` 被提及至少 `PREDICTION_MIN_SUPPORT = 5` 次后，对每个已联结的伙伴 `b`
给出 `p = P(b | a) = 共现(a, b) / 提及(a)`，`p ≥ PREDICTION_MIN_PROBABILITY = 0.5` 才算预测。

**先预测、后学习**：`ingest()` 在 Hebbian 学习之前调用 `prediction_error()`，结果写入
`IngestResult.prediction`（`PredictionError`）。

**误差相对于模型自身的预期**（第一版没有这样做，见 §4）：

- **预期缺席** `missing_ratio`：伙伴 `b` 缺席的代价是 `p`。模型本身预期的缺席量是 `Σ p(1−p)`，
  误差 = `(实际缺席量 − 预期缺席量) / (Σ p − 预期缺席量)`，截断到 `[0, 1]`。概率 0.6 的伙伴
  缺席属于松散簇的正常波动，概率 1.0 的伙伴缺席才是真正的违背。
- **意外组合** `novelty`：两个都达到支持度、却从未共现的概念，按 `1 − exp(−λ)` 计权，
  `λ = n_a·n_b / N` 是在"提及相互独立"的假设下它们本应共现的次数。两个各占一半历史却从未
  相遇的概念一起出现很意外；两个都很少出现的概念第一次相遇则不然。
- `surprise = max(missing_ratio, novelty)`。

`missing` 按 (概率降序, 预测者, 被预期者) 排序，保证跨进程一致。

## 4. 标定

第一版用"原始缺席比例"，阈值 0.6。结构化世界（10 个话题，每次从话题的 6 个概念里抽 4 个）
与随机世界（60 个概念里随机抽 4 个）的平均误差都是 **0.39**：前者是正常抽样波动被算作缺席
（伙伴的条件概率恰好 0.6），后者是意外组合。只调阈值无法兼顾：

| 版本 | 阈值 | 漂移前 / 漂移点 / 漂移后 | 结构化 | 随机 |
|---|---|---|---|---|
| 原始缺席比例 | 0.6 | — | 0.39 | 0.39 |
| **相对预期 + λ 计权** | **0.5** | **0.01 / 0.51 / 0.02** | **0.11** | **0.26** |

（开发中对原始比例也试过更高的阈值：误差下降，但漂移信号随之消失；这里只列出完整测量过的两行。）

相对预期、阈值 0.5：漂移前后接近零、漂移点明显跃升，结构化世界的误差低于随机世界，真正的违背
（常伴概念全部缺席）仍是 1.0。

## 5. 结果

`docs/mc/probes/prediction.py`：

| 观察（两个稳定簇各 20 次之后） | surprise | 说明 |
|---|---|---|
| 完整的 DATA 簇 | 0.00 | 常规 |
| DATA 簇中的 3 个（该世界里从来都是 5 个一起出现） | 0.50 | 缺了两个一向同时出现的伙伴 |
| 只有 `etl job` | 1.00 | 4 个常伴全部缺席 |
| `etl job` + `rollout` | 1.00 | 同上，且是两个熟悉概念的首次相遇（novelty 1.00） |

概念漂移（`pipeline` 前 150 次与 DATA 同现，后 150 次与 ML 同现），每 25 次的平均误差：

```
0.05 0.04 0.01 0.00 0.01 0.01 | 0.51 0.29 0.13 0.05 0.01 0.01
```

误差在漂移点跃升，随着新关联被学到，约 75 次观察内回到基线——一个免费的漂移检测信号。

成本：3 000 次观察灌入 100 话题 × 20 概念，每次观察约 1.6 ms（预测只遍历被观察概念的邻居）。
全部既有测试不变；`tests/test_prediction_error.py`（8 个）。

## 6. 局限与下一步

- **误差尚未被使用。** PP 中误差驱动学习率与注意。两种候选：
  - **注意捕获**：高误差观察中的概念点燃焦点（与第十七轮连接——GWT 中新的感知也会争夺
    工作空间）；
  - **学习调节**：误差高时加快对新组合的学习。但这与第八轮的关联门（防止随机共现造成
    的边蔓延）方向相反，需要先在随机世界里验证不会重新引入蔓延。
- **只有成对预测。** 预测来自两两共现；更高阶的结构（"这三个总是一起出现"）没有建模。
- **新世界没有预测。** 支持度门槛意味着前几次观察总是零误差；旧存储升级后，已联结对的
  计数从零开始积累。
