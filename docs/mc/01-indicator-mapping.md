# 01 · 意识理论指标属性 → World 0 映射

## 1. 方法

Butlin、Long、Elmoznino、Bengio 等人（2023，*Consciousness in Artificial Intelligence:
Insights from the Science of Consciousness*）以"计算功能主义"为工作假设，从五类科学
意识理论中抽取了 14 个**指标属性**：一个系统具备的越多，按这些理论它越"像"一个可能
有意识的系统。他们强调这是可检验的功能清单，而非意识判据。整合信息理论（IIT）与
计算功能主义不相容，没有进入清单；本记录同样不采用 IIT，只在 §5 提一种结构整合度的
代理量。

我们对每个指标问三件事：

1. 它在 World 0（概念认知层）内是否有对应物，还是属于 Agent 的其他部分（LLM、抽取、
   工具、行动循环）；
2. 基线探针（`probes/baseline_indicators.py`）能否观察到它；
3. 补上它能否改善 AGENTS.md 规定的三件事：概念清晰度、激活质量、投影有用性。

## 2. 五类理论（简述）

- **循环加工理论（RPT）**：感知内容要经过反馈式（循环）处理、形成整合的表征才进入意识。
- **全局工作空间理论（GWT，Baars / Dehaene）**：多个并行的专门模块竞争进入一个
  容量有限的工作空间；进入者被"点燃"（非线性地放大、维持）并广播给所有模块；工作空间
  的当前状态决定下一步注意什么，从而能按顺序调用模块完成复杂任务。
- **高阶理论（HOT）**：一个状态被"意识到"，是因为有一个关于它的高阶表征；功能上体现为
  元认知监控——区分可靠表征与噪声，并据此更新信念与行动。
- **注意图式理论（AST，Graziano）**：系统维护一个关于"自己此刻在注意什么、为什么"
  的简化模型，并用它控制注意。
- **预测加工（PP）**：感知是自上而下的预测与自下而上的预测误差之间的交换；误差驱动
  学习与注意。

## 4. 路线图

排序依据：先做**对投影有用性提升最直接、又最不越界**的指标。

| 轮次 | 指标 | 机制设想 | 可观测的验收 |
|---|---|---|---|
| 16 ✅ | HOT-2 | `Projection.epistemic`：概念可靠度（证据分级）、相反主张的争议 / 倾向、渲染中显示每条主张的信念 | 争议对被标出且给出双方信念；一次性概念标为 thin evidence；共现边不冒充主张 |
| 17 ✅ | GWT-4 + GWT-2 点燃 + AST-1 | 在 `context/` 中维护一个容量有限、按认知时钟衰减的**焦点（workspace）**：上一次投影中越过点燃阈值的概念被保持，给下一次激活提供偏置；换任务时释放。每个被选概念记录"为何在此"（种子 / 任务点名 / 焦点延续 / 经由哪条关系） | 同一任务的连续查询保持连贯；换任务后焦点在有限步内释放；不出现固着（perseveration） |
| 18 | PP-1 | 用 Hebbian 关联作为预测：摄入时报告**意外共现**（关联极低的新组合）与**预期缺席**（强关联伙伴没有出现）；评估误差能否用于调节学习或注意 | 误差信号区分常规观察与新颖观察；不增加随机世界中的边蔓延 |
| 之后 | HOT-3 | 投影选择使用元认知：例如一次性概念不应仅凭新鲜度排到老概念之前（基线中 `quantum annealer` 排第 3） | 选择对"证据薄弱"敏感但不压制真正的新信息 |
| 之后 | RPT-1 | 激活的有限次反馈迭代（再入），检验是否改善收敛与桥接概念 | 基准不退化；桥接概念排序更稳定 |

## 5. 不做什么

- 不实现也不声称"意识"、"感受"、"自我意识"。
- 不计算 IIT 的 Φ（与本工作的功能主义假设不相容，且计算上不可行）。如需要，可在投影子图
  上计算结构整合度的代理量（例如投影内关系的连通度），但它只是投影质量指标。
- 不把焦点（第十七轮）做成记忆：它是短时、有容量上限、会衰减的**注意状态**，属于
  AGENTS.md 所说的 Context（"决定此刻什么重要的活跃条件"）。
