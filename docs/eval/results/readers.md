**读出来的东西**：

- **World 0 在 1 200 token 下是真实读者得分最高的条件**（0.95 [0.92, 0.97]），600 token 下 0.92，与 `state_doc`（0.93，1 091 token）
  同一区间；`fact_task` 0.91 用 182 token。四者的差别在自助区间内，与理想读者下的排序一致（§3 的 tables）。
- **直接上下文 0.74**，而且在 17% 的过期问题上把已被更正的旧主张当成现状——Haiku 4.5 读 3.9 万 token 的全部历史时，既漏东西、
  也不可靠地应用"更正"。第三版的 1.00 是在 2.4 万 token、另一套读者设置下得到的（见下），两者不能直接比；能说的是：
  "把全部历史放进上下文最稳妥"只对读得完、读得准的读者成立，不是无条件的。结构化系统（World 0 的硬撤回、事实库的删除）
  把"更正"做在写入侧，读者不必自己做：过期主张被提到的比例全部为 0%。
- **chain（依赖闭包）** 是 World 0 相对事实库 / 紧凑出厂配置的主要优势来源（0.96 对 0.71 / 0.77），与理想读者下一致。
- 所有条件的回答里概念 id 占 0%（紧凑渲染成为默认之后，第三版 54–59% 的 id 回答消失）。
- detail（票据号）按设计为 0：World 0 不存情景细节。
