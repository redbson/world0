# World 0：一种面向 LLM Agent 的概念世界认知层

## 摘要

大语言模型驱动的 Agent 在复杂任务中表现出两类结构性缺陷：其一，任务理解主要依赖局部对话窗口，难以形成稳定、可演化的概念结构；其二，现有外部增强机制在"记忆存储""知识图谱""文档检索"之间摇摆，缺少一层专门服务于**理解**的中间表示。本文提出 **World 0**，一种面向 LLM Agent 的概念世界认知层。World 0 不以事实存储为中心，也不以传统本体建模为目标，而是将 **概念（Concept）**、**关系（Relation）**、**上下文（Context）**、**激活（Activation）**、**投影（Projection）** 与 **视角（Perspective）** 组织为一套可计算、可持久化、可由 LLM 读写的认知结构。其核心机制包括：（1）一个**三轴关系模型**（positive / negative / parallel），将结构强度与传播强度分离，使"互斥"等负向语义成为激活的抑制信号而非弱激励；（2）**双通道扩散激活**，传播同时受任务亲和、视角权重、时间新鲜度与节点置信度调制；（3）基于 MMR 的**可解释投影**，每个投影概念携带其最佳激活路径，负向关系作为反信号单独呈现；（4）**视角条件化**，同一概念世界在调试、设计、研究等视角下产出不同投影；（5）一组维持结构稳定的**认知动力学**——Hebbian 共现学习、成熟度生命周期、分层时间衰减，以及由稳定群落自发产生、沿关系扩散、失去支撑后自然褪去的**色场**领域感知；（6）一条 **使用反馈闭环**，使投影质量随实际使用收敛。本文阐述 World 0 的问题定义、系统模型、动力学机制与实现，报告确定性离线评测基线（种子解析率 1.0，R@8 = 1.0，NDCG@8 ≥ 0.915，抑制正确率 100%），并给出针对 Agent 增益的消融实验设计。我们认为，从"存储增强"走向"认知增强"，关键不在于扩大图的规模，而在于为 Agent 提供一个任务条件下**可投影、可解释、可演化**的局部世界。

**关键词：** LLM Agent，Concept World，Cognitive Layer，Spreading Activation，Projection，Perspective，Contextual Relevance

## 1. 引言

随着大语言模型（LLM）从单轮问答系统演化为具有规划、工具使用与长期任务处理能力的 Agent，如何为 Agent 提供稳定、任务相关、可积累的认知结构成为核心问题。当前主流方案大致分为四类：

1. 基于对话历史或摘要的上下文压缩方案；
2. 基于向量检索的相似内容召回方案；
3. 基于知识图谱或实体关系图的结构化方案；
4. 基于记忆库、日志库或文档库的外部存储方案。

这些方案各有价值，但共享一个隐含假设：**Agent 的问题是"记不住"**。纯历史摘要保留语言连续性却难以维持概念边界；向量检索召回相似片段却缺乏结构解释性；知识图谱强调实体与事实，其完备性目标与 Agent 的任务理解需求并不对齐；记忆库与文档库本质上是存储系统。

而 Agent 在真实任务中需要回答的，往往不是"我曾经看过什么"，而是：

- 当前任务中哪些概念正在发挥作用？
- 这些概念之间的关键关系是什么——包括哪些概念**相互排斥**？
- 在不暴露整个知识世界的前提下，应该向模型注入怎样的局部认知视图？
- 同一个世界，在调试视角与设计视角下，应当呈现出怎样不同的面貌？

基于这一观察，本文提出 **World 0**：一个不追求"覆盖整个世界"，而追求"在任务中产生可用局部世界"的认知层。World 0 的设计目标不是替代知识库、记忆系统或检索系统，而是在它们之上提供一层**概念优先、关系优先、上下文敏感、投影导向**的理解结构。

本文的贡献：

1. 提出"理解问题"与"存储问题"的明确分离，并给出一个以**投影**为唯一操作输出的系统形式化；
2. 提出三轴关系模型与结构/传播强度分离，使负向语义在动力学中获得正确表达（抑制而非弱激励）；
3. 提出任务感知、视角感知、时间感知的双通道扩散激活与基于 MMR 的可解释投影机制；
4. 提出一组保持概念世界长期稳定的认知动力学（Hebbian 学习、生命周期、分层衰减、群落色场），并证明色场演化的有界性（防污染）；
5. 给出完整开源实现（约 1000 个确定性测试）、离线评测基线与 Agent 消融实验设计。

## 2. 问题定义

### 2.1 从存储问题到理解问题

我们将 Agent 面临的问题区分为四个层级：

- **存储问题**：信息如何被保存；
- **记忆问题**：过去事件如何被回忆；
- **事实问题**：实体与事实如何被表示；
- **认知问题**：当前任务应如何被理解。

World 0 只显式解决第四类问题。它不试图成为事实数据库，也不替代事件记忆，而是为 Agent 建立一个"面向任务理解的概念世界"。这一边界在工程上是硬约束：系统的应用层（包括一个可自主运行的 agent 个体）只能通过公开的认知接口操作世界，情节性记忆永不进入核心模型。

### 2.2 形式化目标

给定观察流 $O = \{o_1, o_2, \dots\}$（每个观察包含概念候选、关系候选、任务标签与来源），系统维护一个概念世界 $W_t = (V_t, E_t)$，其中节点带认知状态（置信度、成熟度、激活历史、领域分布），边带三轴类型与双重强度。在任意上下文 $c = (\text{task}, \text{perspective}, \text{now})$ 与种子集 $S$ 下，系统须生成局部投影 $P_c(W_t, S)$，满足：

1. **相关性**：投影概念与当前任务高度相关；
2. **结构性**：投影包含可解释的类型化关系，含负向反信号；
3. **局部性**：投影紧凑（默认 ≤ 15 概念），不暴露全局结构；
4. **上下文敏感性**：$c \neq c' \Rightarrow P_c \neq P_{c'}$（相同种子，不同任务/视角，不同投影）；
5. **可解释性**：每个入选概念可给出其被激活的路径；
6. **演化性**：$W_t$ 随观察与使用反馈持续更新，且长期不退化为噪声；
7. **可操作性**：投影可直接渲染为 LLM 可读的结构化文本。

## 3. 系统模型

World 0 建立在六个一等对象之上（概念卡作为概念的记录形态附属于概念）。

### 3.1 Concept：带认知状态的语义单元

概念 $v$ 携带置信度 $\text{conf}_v \in [0.01, 1]$、成熟度 $m_v \in \{\text{embryonic}, \text{developing}, \text{established}, \text{core}, \text{fading}\}$、激活/证伪计数与时间锚点。置信度更新采用递减收益：

$$
\Delta^{+} = \frac{0.06}{1 + 0.08 \cdot n_{\text{act}}}, \qquad
\Delta^{-} = \frac{0.06}{1 + 0.08 \cdot n_{\text{dis}}}
$$

越成熟的概念越难被单次事件改变。概念的同一性不依赖字符串相等，而由级联归并机制决定：语义身份键（kind/sense/domain）精确匹配 → 同义词复合评分（阈值 0.78）→ 签名 token 集 Jaccard 相似度（阈值 0.6，跨域惩罚 ×0.3）。同名不同义的概念（如 Apple 公司 / 苹果水果）通过 sense 与 domain 保持区分，并支持显式 merge / split 身份操作。

### 3.2 Relation：三轴模型与双重强度

关系类型收敛为三条认知轴：

| 轴 | 轴级传播系数 | 语义 |
|----|------------|------|
| positive | 1.00 | 依赖、包含、使能、共创——激励 |
| parallel | 0.75 | 等价、重叠、共鸣——共振 |
| negative | 0.60（抑制系数） | 互斥、冲突、约束违反——**抑制** |

轴之下是 26 个语义关系（dependence、enables、equivalence、overlap、disjointness、conflict 等），每个携带两种独立强度：**结构强度**（作为结构事实的强度）与**传播强度**（传导激活的强度）。这一分离是本模型的关键：负向关系结构强度很高（disjointness 0.95）而传播强度极低（0.05）——"A 与 B 互斥"是强结构事实，但绝不应把激活从 A 传给 B；它应当**压制** B。

关系还携带语义置信度 $p$（"给定当前世界与证据，该类型关系成立的概率"），按证据融合更新：

$$
p' = \frac{p \cdot s + p_{\text{prior}} \cdot 1.0 + p_{\text{evidence}} \cdot 2.0}{s + 3.0}, \qquad
s = 2 + n_{\text{reinf}} + n_{\text{dis}} + n_{\text{obs}}
$$

旧信念不被单次抽取覆盖；文本证据权重高于类型先验；重复观察提高稳定性。

显式关系与统计关系遵循不同上限：Agent 显式声明的关系权重可达 1.0，Hebbian 共现自发现的关系上限 0.7 且强化收益更低——**显式结构知识天然高于统计共现**。

### 3.3 Context：任务亲和作为分级信号

上下文 $c = (\text{task}, \text{perspective}, \text{now})$ 贯穿激活与投影。任务与历史标签的匹配是分级 token 包含而非字符串相等：

$$
A(\text{task}, h) = \max_{e \in h} \frac{|T_{\text{task}} \cap T_e|}{|T_{\text{task}}|} \quad (\text{子串匹配时取 } 1.0)
$$

亲和度低于门槛 0.34 视为巧合、不予加成；达标后加成 $\beta_{\text{task}} = 1 + 0.5 A \in [1.17, 1.5]$，同时作用于关系的任务历史与概念的强化日志。

### 3.4 Activation：双通道扩散激活

激活从种子做广度优先扩散，但维护两条独立通道。**激励通道**（positive/parallel 边）的一跳传播为乘法链：

$$
a_{d+1}(v_j) = a_d(v_i) \cdot w_{ij} \cdot \omega_P(\rho_{ij}) \cdot \max(\text{conf}_j, 0.3) \cdot \delta^{\,d+1} \cdot \beta_{\text{task}} \cdot \beta_{\text{dom}} \cdot \varphi_{\text{rel}} \cdot \varphi_{\text{node}}
$$

其中 $w_{ij}$ 为边权；$\omega_P(\rho)$ 为视角对语义关系 $\rho$ 的权重（三层级联：语义关系级覆盖 → 轴级覆盖 → 全局轴默认）；$\max(\text{conf}_j, 0.3)$ 为邻居 readiness；$\delta^{d+1}$ 为深度衰减；$\beta_{\text{dom}} \in \{1.0, 1.3\}$ 为视角领域加成；$\varphi_{\text{rel}}, \varphi_{\text{node}}$ 为关系与概念的时间新鲜度（只读软衰减，半衰期分别为 $72(1+0.5n_{\text{reinf}})$ 小时与 168 小时，下限 0.15 / 0.1）。

**抑制通道**：negative 边将 $\text{raw} \times 0.6$ 累积为独立的抑制量，不向外传播。净激活：

$$
\text{net}(v) = \max\big(0,\ \text{act}(v) - \text{inh}(v)\big)
$$

被强烈排斥的概念即使存在弱激活路径也会从投影中消失。此外设有传播地板（$0.03 \times$ 最大种子激活）保证激活边界上的概念仍能收到最小信号；多源激活按最大值合并并记录最强路径。

### 3.5 Projection：可解释的 MMR 选择

投影分四步。**种子解析**采用四层级联（精确名/别名 → 视角领域消歧 → 模糊签名匹配，阈值 0.45 → 未解析），每个种子的解析方式透明记录——被猜测或未命中的种子绝不静默。**候选相关性**：

$$
\text{rel}(c) = \frac{a(c)}{a_{\max}} \cdot \big(0.6 + 0.4 A_c\big) \cdot \beta_{\text{dom}} \cdot \big(0.7 + 0.3\varphi_c\big)
$$

**MMR 贪心选择**平衡相关性与多样性（$\lambda = 0.3$）：

$$
\text{MMR}(c) = (1-\lambda)\,\text{rel}(c) - \lambda \max_{s \in \mathcal{S}} J\big(N(c), N(s)\big)
$$

冗余度为候选与已选概念邻域集合的最大 Jaccard 相似度——入选概念应覆盖结构上不同的邻域。**渲染**支持三种风格（default / compact / detailed），detailed 风格附带每个概念的最佳激活路径（"为何入选"）与全部负向关系（counter-signals）。投影输出为 markdown，直接注入 Agent prompt。

### 3.6 Perspective：角色条件化的认知透镜

同一概念世界在不同视角下应产出不同投影。视角通过单个**语义关系级**的权重覆盖介入传播（而不仅是轴级），并通过 `active_domains` 实现领域聚焦与种子消歧。内置四个 profile：

- **debug**（工程师）：dependence 1.4、enables 1.3、conflict 1.2、overlap 0.5——沿依赖链追因果，压制松散相似；
- **design**（架构师）：overlap 1.4、equivalence 1.3、co_creation 1.3、dependence 0.8——寻找同构与组合机会；
- **research**（研究者）：similarity_kernel 1.4、overlap 1.3、persistent_attention 1.2——放大类比与长期关注信号；
- **default**：中性。

自定义视角可持久化注册，亦可内联传入。

## 4. 认知动力学

概念世界若只生长不约束，会退化为语义蔓延。World 0 的稳定性来自四组动力学。

### 4.1 Hebbian 共现学习（带阈值）

同一观察中共现的概念对累积共现计数，达到阈值 2 才创建一条弱 parallel 边（单次偶然共现不产生结构）；单次观察最多处理 30 对；自发现关系权重上限 0.7。系统因此同时支持"用户明确声明的关系"与"从重复共现中逐步发现的关系"，且后者永远不会压过前者。

### 4.2 成熟度生命周期

$$
\text{embryonic} \xrightarrow{n_{\text{act}} \geq 3,\ \text{conf} \geq 0.3} \text{developing} \xrightarrow{n_{\text{act}} \geq 10,\ \text{conf} \geq 0.6} \text{established} \xrightarrow{n_{\text{act}} \geq 30,\ \deg \geq N^*} \text{core}
$$

其中 core 的连接要求随激活次数动态放宽：$N^* = \max(2,\ 5 - \lfloor (n_{\text{act}} - 30)/20 \rfloor)$。置信度跌破 0.05 转入 fading，重新激活则复活为 developing。

### 4.3 分层时间衰减

无活动概念按指数衰减，半衰期随成熟度分层：embryonic 24h、developing 1 周、established 1 月、core 3 月——未经验证的概念一天内褪去，中枢概念抵抗遗忘。关系半衰期 $72(1 + 0.5 n_{\text{reinf}})$ 小时，被反复确认的关系衰减更慢。fading 且置信度 < 0.02 的概念、权重 < 0.02 的关系在 reflect 时修剪。硬衰减只发生在 reflect；读路径上的新鲜度是只读软衰减，不改写库中状态。

### 4.4 群落与色场：自组织的领域感知

`reflect()` 执行确定性标签传播（≤8 轮，可复现）检测概念群落，耦合考虑时间新鲜度：$K_{ij} = w_{ij} f_{\text{axis}} \varphi_{\text{rel}} \bar{\varphi}_{\text{node}}$。稳定群落（重现 ≥ 2 次、规模 ≥ 3）自发"生色"：颜色注入其成员的领域分布（core 成员 0.65、普通成员 0.35），沿关系饱和扩散（$c' = c + a(1-c)$，速率 0.18、每步衰减 0.62），失去邻域支撑后按缺口比例褪色、极弱分量蒸发。统一演化方程：

$$
\frac{dc^{\alpha}}{dt} = -\eta^{\alpha}(t)\, L_t\, c^{\alpha} + s^{\alpha}(t) - \mu^{\alpha}(t) \odot c^{\alpha}
$$

扩散项、源项与褪色项共同保证**正性、有界性与无源衰减**——颜色有源（稳定群落）有汇（褪色与蒸发），不会发生无限污染；处于两个群落支撑下的概念形成稳定的混色边界层而非污染。色场是"结构先于颜色"的：领域感知由群落结构自发产生，再被视角的领域聚焦与种子消歧消费。

### 4.5 网络熵诊断

为监控世界是聚焦还是弥散，系统计算每个概念局部关系分布的归一化 Shannon 熵，并按节点重要性（置信度 × 成熟度因子）加权为世界熵。经验区间：0.20–0.45 结构化且聚焦；> 0.70 弥散、疑似噪声。该诊断为纯读取，是后续所有调优工作的观测基础。

### 4.6 使用反馈闭环

投影的消费者可通过公开接口反哺使用结果：有用概念被强化、缺失概念被创建、噪声概念被降权（−0.05）、弱关系被削弱、有用关系被确认。关系引用支持人类可读标签（`"src -> relation -> tgt"`）。由此，世界的演化不只来自被动观察，还来自**使用结果**，投影质量随使用闭环收敛。

## 5. 系统实现

实现为 Python 库（pydantic 数据模型，约 1000 个确定性测试），核心 API 极小：

$$
\text{ingest}(o) \quad \text{ingest\_text}(t) \quad \text{project}(S; \text{task}, \text{perspective}) \quad \text{reflect}() \quad \text{apply\_feedback}(\cdot)
$$

辅以身份操作（merge / split / weaken）、状态诊断与可视化。模块按"乐高积木"原则组织：concepts / relations / dynamics（六个引擎）/ communities / projection / perspectives / extraction / store，跨模块调用仅依赖 Protocol 契约，任何实现可替换。

**写入方向**：原始文本经 LLM 抽取为结构化 Observation（概念 + 类型化关系 + 义项/领域标注），本地校验（端点存在性、自环过滤、非法类型回退）后进入标准摄入管线：概念 get-or-create 与归并 → 显式关系创建/强化 → Hebbian 学习 → 色场注入 → 批量刷盘。一项 9 模型 × 3 轮的模型 × prompt 评测表明：**prompt 是抽取质量的主导杠杆**——生产 prompt 下结构质量（同义归并、义项拆分、关系方向、矛盾浮现、中文保持）基本与模型无关，因此默认提取模型取顶级梯队中成本最低者（gpt-5.4-nano，9.0/9）。

**读取方向**：用户查询 → 种子解析 → 双通道激活 → MMR 投影 → markdown 渲染 → prompt 注入。时钟可注入（`now=`），全链路确定性可评测。

**持久化**：概念与关系为独立 JSON 文件，脏标记批量刷盘于 ingest/reflect 边界；Store 接口抽象可替换后端。

**边界**：应用层包含一个可自主运行的 agent 个体（自主照料并生长概念世界），但它只通过公开 World facade 行动；概念性自我存于 World 0，情节性自我（日志）存于 agent 层——"World 0 不是记忆系统"的边界在自主场景下依然成立。

---

## 6. 评测

### 6.1 确定性离线基线

在固定的、LLM 无关的概念世界上，对投影质量做确定性评测（指标：种子解析率、P@k、R@8、NDCG@8、噪声混入率、类型化关系占比、抑制正确性）。当前基线（默认视角）：

| 用例 | seed_rate | P@5 | P@8 | R@8 | NDCG@8 | noise | typed | inhibition |
|------|-----------|-----|-----|-----|--------|-------|-------|------------|
| ml_from_serving | 1.000 | 0.600 | 0.750 | 1.000 | 0.915 | 0.250 | 0.389 | ok |
| ops_from_serving | 1.000 | 0.800 | 0.750 | 1.000 | 0.971 | 0.250 | 0.333 | ok |
| typo_seed | 1.000 | 0.600 | 0.750 | 1.000 | 0.915 | 0.000 | 0.389 | ok |

三个结果值得强调：（1）**上下文敏感性是真实的**——ml 与 ops 两个用例共享同一种子（model serving），仅任务不同，投影各自命中其黄金集且满召回；（2）**拼错的种子被模糊解析完全恢复**（typo_seed 与正确种子结果一致且零噪声）；（3）**抑制全部正确**——应被压制的概念无一泄漏。当前的主要弱项是 typed_ratio（约 0.33–0.39）：投影内仍有较多 generic 关系，是已知的改进方向。

### 6.2 系数敏感性

对 MMR λ 与传播地板比例的扫描显示参数对质量有显著影响（最优组合下 P@6 从 0.333 提升到 1.000）。系统选择将其作为**人工可解释的调参辅助**而非自动调优器，避免针对小评测集过拟合。

### 6.3 Agent 增益的消融实验设计

离线指标衡量投影本身；World 0 对 Agent 的真实增益需消融实验验证。实验至少含三组：

1. **No Memory**：不提供历史结构；
2. **Raw History**：提供原始历史或普通摘要；
3. **World 0 Projection**：经 World 0 沉淀并投影。

控制变量：模型版本、任务集、token 预算、最大轮数、系统提示骨架、工具可用性——唯一变化是"是否使用 World 0 投影"。任务集应覆盖多轮累积、跨会话桥接、长距离概念召回、关系推理（含负向关系：模型是否避开被标注互斥的方案）与上下文切换。记录任务成功率、概念 P/R、关键关系命中率、上下文聚焦度、token-per-success。待验证假设：

- **H1**：World 0 提高多轮任务的结构化正确率；
- **H2**：World 0 提高跨域桥接任务的关系识别率；
- **H3**：相同 token 预算下，World 0 投影的上下文聚焦度更高；
- **H4**：增益主要来自结构化投影（含反信号），而非"更多历史文本"；
- **H5**：视角条件化在角色明确的任务上优于中性投影。

## 7. 相关工作

**Agent 记忆系统。** Zep/Graphiti 以双时态知识图维护事实边的有效区间，检索为语义 + BM25 + 图的混合；Mem0 及其图变体抽取并整合记忆项，附实体关系与冲突检测。两者的一等单位是事实/记忆项，回答"我记得什么"；World 0 的一等单位是概念，输出是任务条件投影，回答"应如何理解"。

**结构化检索。** HippoRAG 受海马体索引理论启发，以 KG + 个性化 PageRank 做单轮多跳检索；GraphRAG 以 Leiden 分层社区与多级摘要支持全局意义建构。两者的上下文条件是查询相似度或模式切换（local/global）；World 0 的任务条件是连续的（分级亲和度调制每一跳传播），且投影经 MMR 塑形为紧凑非冗余视图，更接近上下文工程而非 top-k 检索。

**演化型笔记。** A-MEM 以 Zettelkasten 风格组织 agent 记忆，新笔记到达时重评邻域链接，是少数具有"演化"性质的系统。World 0 的演化更深一层：成熟度生命周期、分层衰减、Hebbian 学习与群落色场使结构本身具有生灭动力学，而不仅是链接重组。

**认知理论。** Gärdenfors 的概念空间把概念建模为几何凸区域；ACT-R 的检索结合基准激活（使用衰减幂律）与上下文扩散激活。World 0 可视为这两条传统在 LLM Agent 工程语境下的操作化：扩散激活被扩展为任务/视角/时间调制的双通道形式，概念的"区域性"以义项、领域与色场近似表达。

与上述所有系统的根本差异在于边界选择：World 0 **拒绝**成为事实数据库或记忆库，它假设这些由相邻系统承担，自身只负责概念组织与认知投影——这一收窄使"投影质量"成为可独立度量、可独立优化的目标。

---

## 8. 局限性

1. **对抽取质量的依赖**：概念与关系的初始质量受抽取模型影响。评测显示 prompt 是主导杠杆且本地校验能拦截结构性错误，但语义偏差无法完全消除。
2. **类型化关系占比仍低**：基线 typed_ratio ≈ 0.33–0.39，generic 关系仍多，关系细化（refinement）机制有待加强。
3. **评测集规模有限**：离线基线用例少、为构造数据；系数敏感性结论可能不外推。Agent 消融实验（§6.3）尚未执行，端到端增益仍是假设。
4. **色场处于早期阶段**：当前按"萌芽—感知—稳定—共生—成熟"的渐进路径只做观测与解释，尚未正式参与投影重排序。
5. **上下文模型仍偏轻量**：任务以标签 + 分级 token 匹配表达，尚无显式可组合的上下文对象图。

## 9. 未来工作

1. 执行 §6.3 的 Agent 消融基准，验证 H1–H5；
2. 关系细化机制：以使用反馈与重复观察将 generic 关系升级为类型化关系，提升 typed_ratio；
3. 色场进入"共生期"：以群落色彩轻度参与投影 rerank，并以网络熵守护其不引入弥散；
4. 显式上下文对象与上下文组合代数；
5. 可学习的投影打分（以离线指标 + 使用反馈为信号），同时保持解释性约束；
6. 与外部记忆/文档/检索系统的分层协作协议——World 0 提供概念支架，相邻系统按概念锚点挂载事实与情节。

---

## 10. 结论

本文提出了 World 0，一种面向 LLM Agent 的概念世界认知层。与知识图谱、记忆系统和向量检索不同，World 0 不以事实覆盖或存储规模为目标，而以**概念结构、三轴关系、任务激活与可解释局部投影**为核心。其关键设计——结构强度与传播强度分离、抑制作为独立通道、视角的语义关系级加权、带阈值的统计学习永远低于显式声明、结构先于颜色的自组织领域感知、读路径不写库的软/硬衰减分离——共同服务于一个目标：让 Agent 在任务当下获得一个"足够小、足够准、足够有结构"的局部世界，并让这个世界随观察与使用持续演化而不塌缩为噪声。我们认为，这种从"存储增强"走向"认知增强"的转向，是 LLM Agent 基础设施中值得系统研究的方向。
