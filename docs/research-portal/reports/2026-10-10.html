Remember Before You're Asked: MemDream for Self-Probing Memory Evolution

Authors not recovered · 2026-09 · arxiv:2609.34545 · paper page

Verification: search-summary-only

Core Thesis AUTHOR CLAIM

Memory should be repaired offline before retrieval fails, via self-probing dream cycles.

Theoretical Foundations AUTHOR CLAIM

Not recorded.

Proposed Mechanism AUTHOR CLAIM

Offline dream cycles with three agents (Dreamer, Analyst, Consolidator) that probe, diagnose and repair a memory graph; policy trained with GRPO; soft decay gives reversible forgetting; online interaction continues during consolidation.

Experimental Evidence REPORTED RESULTS

Numerical results not recovered in this session.

Limitations AGENT INTERPRETATION

Unverified: benchmark coverage, RL training cost, whether repairs introduce semantic drift.

World0 Implications AGENT INTERPRETATION

Maps directly onto a World0 Dream Mechanism: probe the concept-world with synthetic task contexts, diagnose weak projections, repair relations. Reversible decay matches the 'never silently delete' stance. Complexity: medium-high; start with a non-RL probe/diagnose/repair loop using the existing projection eval scripts.
