# World 0 路线图：0.3.0

> 上一个发布版本是 0.2.0（"可配置的概念系统"）。此后 `dev` 上累积了 26 轮工作（`CHANGELOG.md` 的
> Unreleased 节、分析文档 §7、论文、LongRun 评测）。0.3.0 是把这些工作收口成一个版本：
> **一个随观察流连续演化、读写都与 reflect 调度无关、能在长期运行的 Agent 里与配置良好的结构化记忆打平的认知层。**

版本号沿用 `pyproject.toml` 的语义化版本：0.x 阶段，0.3.0 是下一个"大版本"（接口可以不兼容 0.2.0）。

## 0.3.0 的定义

一个版本的边界由"链条"决定（AGENTS.md）：定义概念 → 概念卡 → 类型化关系 → 任务语境下的相关性 → 激活局部邻域 →
投影任务级视图。0.3.0 要求这条链的每一环都满足：

| 环 | 0.3.0 的要求 | 状态 |
|---|---|---|
| 概念 | 身份与合并 / 拆分有索引；成熟度、存在性是观察流的函数，与 reflect 调度无关（定理 3.7、F6、F7） | ✅ 第 20–21 轮 |
| 关系 | 主张身份为 (源, 目标, 轴, 标签)；方向、撤回、否证、支持度；负向主张带信念；别名不夸大 | ✅ 第 15、19、23、25 轮；别名与对立读法 → 第 28 轮 |
| 语境 | 任务词按区分度加权；主张的语境是陈述它的任务；没见过的任务靠名字锚定 | ✅ 第 14、22 轮 |
| 激活 | 有界 noisy-OR、秩保持地板、读取时结算；一次陈述的冲突要能把对方带进视图 | ✅ 第 3、23 轮；冲突可见 → 第 28 轮 |
| 投影 | 紧凑渲染是默认；种子永远在；任务语境拆分；**只放任务能到达的东西，不用别的任务的概念填满预算** | ✅ 第 10、22、24 轮；填充规则 → 第 27 轮 |
| 演化 | 单一认知时钟、SQLite 后端、学习状态摊销持久化、剪枝宽限；**reflect 独有的删除只剩 Hebbian 再验证** | ✅ 第 1、5、12、13 轮；再验证 → 第 29 轮 |
| 证据 | 形式化论文 + 数值验证；LongRun 可复现评测；真实 LLM 抽取；**真实读者阶段用当前代码重跑** | ✅ 论文、第 25–26 轮；读者阶段 → 第 30 轮 |

### 本版本收口的工作（第 27–30 轮）

1. **第 27 轮 — 投影不用别的任务的概念填满预算。** LongRun 的 focus 查询里，World 0 展示的主张 20% 来自另一个领域
   （沿桥接概念漂过去的邻域）、25% 是第三跳；在 40×40 的大世界里综合分降到 0.86。规则：有已知且不同语境
   （任务画像与当前任务的亲和度 < `CONTEXT_MATCH`）的候选只能凭自身分数进入视图，当前语境的候选用尽时停止，
   `max_concepts` 是上限不是目标。没有任务、或没有任何候选在当前语境里（标签错）时行为不变。
2. **第 28 轮 — 关系语义。** (a) 一次陈述的 `conflict` 让对方可见：负向边给对方"可见性"激活（终点，不再向外扩散），
   抑制通道只压制经其他路径到达的激活；(b) 新增 `contrast` 语义关系（设计哲学里的一等关系，弱于 `conflict`），
   `contrasts` 别名不再被读成 `conflict`；(c) `part_of` 读成 `inclusion`（整体为源），与抽取 prompt 一致；
   (d) 轴名（`positive` / `negative` / `parallel`）与 `mutual_understanding` 等旧别名映射到该轴上最弱的关系，
   不再夸大。
3. **第 29 轮 — Hebbian 再验证与调度无关。** 关联已低于移除线的共现边在读取与事件上视为已死，不等 reflect；
   定理 3.7 的最后一个前提消失。
4. **第 30 轮 — 评测刷新。** 模板文本用当前 prompt 重新抽取；真实 LLM 读者阶段用当前代码重跑（紧凑渲染、撤回、
   语境拆分）；报告第五版。

## 推迟到 0.4

- `confidence` 完全成为导出量（`evidence × g(salience)`）；只追加的事件日志与快照。
- 对立读法互相支持（`A depends on B` / `B enables A`；`inclusion` / `membership`）——是否视为同一事实。
- 抽取压测用与 prompt 例句无关的改写句式（目前 seed 1–2 是新事件、不是新措辞）。
- 评测补测：遗忘的收益、视角与别名、标签部分准确。
- MC 方向：HOT-3 元认知驾驭选择；点燃反馈到激活；预测误差驱动学习或注意；PKM 开启 `sustained_attention`。
- Agent 功能（`TODO.md` P1/P2）：概念卡编辑、研究线程、能力矩阵、MCP 服务。
