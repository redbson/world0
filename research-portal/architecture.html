AP-001 Dream Mechanism梦机制 EXPERIMENTAL实验性 PROPOSED已提出

Dream cycle inside reflect(): probe → diagnose → repair在 reflect() 中加入梦循环：探测 → 诊断 → 修复

Component组件: world/_reflect.py · ReflectPipeline

Change改动: Extend reflect() with an optional pass that generates synthetic task contexts, runs project(), scores the projections with the existing eval metrics, and proposes bounded relation edits for weak projections.为 reflect() 增加一个可选步骤：生成合成任务情境，运行 project()，用现有评测指标给投影打分，并对薄弱投影提出有界的关系修改。

Expected benefit预期收益: Finds weak projections before an Agent hits them; keeps repairs explainable because edits are typed relation changes.在 Agent 遇到之前发现薄弱投影；修改是类型化关系的变更，因此修复可解释。

Complexity复杂度: MEDIUM中 · Risk风险: Semantic drift of typed relations; repairs must be reversible (soft decay, no deletes).类型化关系的语义漂移；修复必须可逆（软衰减，不删除）。

AP-002 Cognitive Architecture认知架构 SUPPORTED已支持 PROPOSED已提出

Write-validation gate for LLM-authored cards and relationsLLM 撰写的概念卡与关系的写入校验闸门

Component组件: extraction/ → concepts/ · relations/ managers

Change改动: Insert a validation step between ConceptExtractor output and the managers: duplicate signature check, relation-type check, contradiction check against existing relations; rejected writes are logged, not dropped silently.在 ConceptExtractor 输出与管理器之间插入校验步骤：重复签名检查、关系类型检查、与现有关系的矛盾检查；被拒绝的写入记录日志，而不是静默丢弃。

Expected benefit预期收益: Protects concept integrity (engineering priority 1) as the world grows from LLM writes.在概念世界随 LLM 写入增长时保护概念完整性（工程优先级 1）。

Complexity复杂度: LOW低 · Risk风险: Over-strict gates could block legitimate concept evolution; needs a tunable threshold.过严的闸门可能阻断合理的概念演化；需要可调阈值。

Findings发现: F-20261010-03 · Evidence证据: EV-003, EV-004 · Experiments实验: E-002

AP-003 Dynamic Ontology动态本体 SPECULATIVE推测性 PROPOSED已提出

Projection-feedback relation weighting投影反馈驱动的关系加权

Component组件: relations/ weighting · dynamics/ HebbianEngine

Change改动: Feed projection outcomes (used / unused / contradicted in the downstream task) back into relation weights with bounded updates, alongside the existing co-occurrence Hebbian updates.把投影结果（在下游任务中被使用/未使用/被反驳）以有界更新的方式回馈到关系权重，与现有的共现 Hebbian 更新并行。

Expected benefit预期收益: Relation weights reflect operational usefulness, not only co-occurrence.关系权重反映实际使用价值，而不只是共现。

Complexity复杂度: MEDIUM中 · Risk风险: Feedback loops can entrench early relations; needs decay and stability tests.反馈回路可能固化早期关系；需要衰减与稳定性测试。
